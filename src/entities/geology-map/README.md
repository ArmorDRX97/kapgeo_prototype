# Карты месторождения

`fieldScene.ts` создаёт фиксированный вымышленный фонд из 8 215 скважин. Расположение приближено к трём пользовательским изображениям старой системы: 6 600 скважин образуют плотную полосу с северо-запада на юго-восток с разрывами и пропусками, 1 200 — отдельную северную группу, 415 — редкую разведочную сеть и удалённые профили. Координаты слегка смещены, пять типов перемешаны. Профили и соединения привязаны к устьям; области и блоки служат визуальным контекстом. Это оформление прототипа, а не результат геологического расчёта.

Интерактивный план `MAP-FIELD` показывает весь набор. Вход через меню и `/geology/plans` открывает его автоматически; старые планы доступны в реестре. Для новой геометрии используется отдельное оформление `kapgeo.geology.field-layout.v2` и отдельная позиция камеры. Предыдущая запись v1 сохранена и включается в скачиваемую исходную копию. Карта разрезов использует те же исходные скважины и профили без областей, блоков и соединений. Правки интерактивного плана сохраняются отдельно от исходного набора и не меняют данные разрезов. Прежний редактор геометрии текущего разреза доступен через переключатель карты.

Общие компоненты карты находятся в `ui/`: на больших сценах скважины рисуются Canvas, остальная геометрия — SVG. Подписи появляются при приближении, поиск охватывает весь фонд, списки объектов и выбора опор ограничены с возможностью уточнить поиск. Компактная легенда над картой позволяет скрывать типы, Alt + нажатие оставляет один тип. Поиск перенесён в панель слоёв; селект типа над картой удалён. Разрезы выделены синим, блоки — зелёным, соединения — серо-зелёным; толщина линий увеличена для читаемости. В браузере сохраняются только изменения оформления, без дублирования исходных тысяч объектов.

В разрезах применена такая же компоновка: фильтры над картой, поиск без селекта в панели инструментов, масштабирование в строке заголовка. Панели и отступы уплотнены, чтобы увеличить площадь карты; фильтры доступны и при скрытых инструментах.

## Топографическая подложка

`topography.ts` сопоставляет условную местную сетку с районом Буденовского месторождения: опорная точка X=57500, Y=95200 соответствует примерно 44.75° N, 67.70° E. Оси исходных векторов не меняются. Для отображения используется Web Mercator с поправкой масштаба по широте опорной точки; это визуальная привязка прототипа, не официальное преобразование СК-42 и не реальные координаты скважин.

Местоположение района подтверждают [Казатомпром](https://www.kazatomprom.kz/ru/media/view/kazatomprom_poluchil_pravo_na_razvedku_urana_na_novom_uchastke_mestorozhdeniya_budenovskoe) и [материалы разработки участков 3 и 4](https://ecoportal.kz/Public/PubHearings/LoadFile/202949). Сами синтетические месторождения в БГД не переименовываются.

`TopoBasemap` запрашивает обычные видимые XYZ-плитки `https://tile.opentopomap.org/{z}/{x}/{y}.png` (источник: [OpenTopoMap](https://opentopomap.org/), [условия использования](https://opentopomap.org/about#verwendung)). Масштаб источника ограничен 17; дальнейшее приближение увеличивает существующую плитку. При перемещении ненужные элементы удаляются, новые загружаются, повторные запросы обслуживает обычный кеш браузера. Предзагрузки регионов, скачивания наборов и собственного сервиса плиток нет. Атрибуция OpenStreetMap, SRTM, OpenTopoMap и CC BY-SA видима при включённой подложке. Ошибка загрузки не мешает векторной карте; предусмотрен повтор. Подложка и сетка отключаются независимо во всех трёх подмодулях, включая редактор отдельного профиля.

Контекст для визуальной композиции: `docs-ref/knowledge/modules/geology/cartography/video-details.md` и `docs-ref/knowledge/modules/geology/maps/reference-video-memory.md`. Численность, координаты и распределение типов придуманы для данного сценария, не заимствованы из реального месторождения.

Общие быстрые переключатели `MapLayerToggles` («Карта» и «Сетка») доступны прямо на панелях БГД, интерактивного плана, общей карты разрезов и редактора отдельного профиля. Они независимо управляют видимостью подложек и не меняют векторные объекты.
