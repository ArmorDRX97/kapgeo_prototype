# Работа с внутренней картой

Карта помогает команде обсуждать предметные связи: что создаёт процесс, кто использует результат и какую часть поддерживает система. Она не выполняет производственные расчёты и не изменяет записи пользовательского прототипа.

## Исследование

Выберите один из четырёх режимов: «Процессы», «Специалисты», «Данные», «Модули KAPGEO». Они используют один индекс понятий. Область слева раскрывает группу; карточка открывает подробное объяснение, входы/выходы, участников и связанные элементы. Поиск учитывает названия, описания и синонимы; Ctrl/⌘ K открывает поиск, стрелки/Enter выбирают результат, Escape закрывает список.

«Фокус» оставляет соседей на один или два шага. «Путь» ищет осмысленную цепочку работы/данных либо предметных связей; учебные группы не сокращают путь искусственно. Отсутствующая цепочка объясняется отдельно. Фильтры задают типы элементов, области и смысл связей; пустая группа означает все значения. Фокус, путь и учебный маршрут временно показывают свой контекст поверх фильтров.

Тяните фон для перемещения, меняйте масштаб колесом и кнопками, пользуйтесь мини-картой. Узел перемещается за верхнюю часть с точками. Автоматическая раскладка работает локально в ELK Worker; при ошибке остаётся сетка и кнопка повтора. На кадре ограничено число элементов: широкий выбор предлагает уточнить контекст. История назад/вперёд относится к карте, а верхняя кнопка «В прототип» возвращает рабочий экран приложения.

Можно закрепить до шести понятий. Шесть учебных маршрутов сохраняют этап и завершение; маршрут можно приостановить и продолжить. PNG/SVG экспортируют текущую раскрытую проекцию графа; SVG содержит HTML-карточки через foreignObject. Для графических редакторов с ограниченной поддержкой foreignObject используйте PNG. Экспорт не является чертежом геологического разреза.

## Обновление содержимого

Содержимое лежит рядом с кодом в `data/nodes.json`, `edges.json`, `categories.json`, `learning-paths.json`. Редактор JSON в UI отсутствует. Изменения проходят обычную проверку кода.

Текущее обновление описано [отдельно](./context-update-2026-10-15.md). Каталог `sources.json` задаёт основания; у уточнённых узлов `delivery` показывает степень реализации, `evidence` — источник/раздел. У связей `relationScope` различает предметный смысл, зависимость внутри прототипа и предложение. Не помечайте связь с заглушкой как работающую — это блокирует валидатор. В режиме модулей сначала видны шесть верхних областей; кнопка раскрытия показывает их пункты.

- Новое понятие: уникальный ID, существующая категория, предметный тип, название, краткое описание и все разделы explanation. `parentId` означает учебную вложенность и требует соответствующей связи `contains`.
- Новая связь: уникальный ID, существующие source/target, тип, объясняющие label/description. Циклы предметных связей допустимы, циклы вложенности запрещены.
- Новый маршрут: уникальный ID, описание, длительность и не менее трёх неповторяющихся шагов с существующими nodeId и объяснением каждого перехода.
- Метки `implemented/retained/planned` сверяйте с текущим статусом основного приложения. Смысловая связь не означает наличие backend-интеграции или реализованного расчёта.

После правок: `npm run validate:knowledge-map`, тесты модуля, typecheck и build из корня. Общие test/lint/build также проверяют интегрированную карту. Её внутренние документы не являются частью продуктового UI/UX-ТЗ.
