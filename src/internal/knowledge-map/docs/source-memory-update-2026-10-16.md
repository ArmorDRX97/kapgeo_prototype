# Источниковая карта системы — 16.10.2026

Основание — прямое решение пользователя: обновить карту по памяти всего `docs-ref/files`, исключив текущую готовность React из содержания. Использованы [предметная модель](../../../../docs-ref/knowledge/system/domain-model.md), [18 процессов](../../../../docs-ref/knowledge/system/cross-module-flows.md), [индекс 122 источников](../../../../docs-ref/knowledge/catalog/knowledge-index.md), модульные выжимки, роли, схемы и вопросы. Runtime/код атласа читались для реализации карты; продуктовый frontend не использовался как предметное свидетельство.

## Что изменилось

- 176 → 230 понятий; 511 → 661 связь; 9 → 14 учебных маршрутов. Все старые node IDs сохранены, чтобы ссылки, закрепления и обучение продолжали открываться. `rhythm-excluded` теперь означает ритмопачки из источников, `design-backlog` — открытые вопросы источников, `autonomous-documents` — происхождение/идентичность данных. Это совместимые технические IDs, не старые продуктовые утверждения.
- БГД входит в геологический контур. Карты, разрезы, паспорт, керн, интерпретация и запасы описываются по назначению/входам/выходам, без frontend-статусов.
- Добавлены временная конфигурация и события, транспортный граф отдельно от членства, контрольные точки, остановки, staging/запись импорта, кислота и начальный остаток, насос/двигатель/ПНА, стадии РВР, ТО1/ТО25 и движение запасов.
- Разделены официальный пространственный 2D, legacy геологический 3D и физико-химический ПСВ. ЭАМ получает факты и расчёты, использует дату состояния, выборки и связанные паспорта.
- Сохранены три поколения БД, различие графической связи/SQL FK, 47 двуязычных находок, конфликтующие единицы/nullable и качественные значения. 464 учтённых объекта не объявлены 464 установленными эквивалентами; 141 unmapped сохранён.
- Каталог имеет 122 исходных записи и 11 aliases старых source IDs. Alias явно подписан, не считается независимым подтверждением. Все references ведут в новую память; удалённые папки не используются.

## Границы доказательности

`knowledgeBasis`: source — группа исходников; legacy — поведение по руководствам/демонстрациям; requirement — требования/функциональная структура; open — нерешённый вопрос; context — учебное предметное объяснение. Контекст не повышается до буквального требования или SQL. Внутри карточек требования и старые примеры могут сравниваться; конкретные основания остаются в evidence.

10 областей — учебная организация материала, а не новая административная иерархия заказчика. 14 системных ролей D002 отличаются от четырёх профессий предметного контекста. Имена блоков, дата состояния/замера/отчёта, MD/Z, ручной/AI/принятый результат, исходная/производная запись разделяются.

Карта даёт обзор и маршруты к деталям. Полные 1607 полей D005, 226 деклараций D006, 2415 строк D023, транскрипты и кадры остаются в рабочей памяти; они не превращены в нечитаемый граф всех колонок. ASR и кадровый разбор не объявлены непрерывной ручной проверкой звука/движения.

## Воспроизводимость

`scripts/sync-source-catalog.py` строит каталог из manifest/index. `scripts/update-from-memory.py` содержит явные предметные обновления и строит 18 карточек из источниковой части cross-module-flows; раздел о React из этого файла не читается как данные. Генератор не читает продуктовые исходники. Источниковые файлы и прежние отчёты анализа не меняются.

Проверки: `npm run validate:knowledge-map`, typecheck/test/lint; Vite build с `--emptyOutDir false` в `.tmp/knowledge-map-source-build`, затем `check-isolation.mjs --built --out-dir .tmp/knowledge-map-source-build`. Это эквивалентные стадии сборки без очистки существующего dist: пользователь запретил удаления. Исходы и browser QA записываются в [отчёт обновления](../../../../docs-ref/knowledge/quality/knowledge-map-source-update.json).
