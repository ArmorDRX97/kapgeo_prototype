# Паспорт скважины

Самостоятельный кликабельный подмодуль `/geology/passports?well=PS-101`. Локальные примеры скважин и глубинных данных находятся в `model.ts`; подмодуль не читает и не изменяет БГД, интерпретацию или данные других рабочих областей. Оформление каждой скважины сохраняется отдельно в `kapgeo.passport.design.v1.<id>`. Выбор скважины находится в URL и восстанавливается при возврате через меню геологии.

Основания: `docs-ref/knowledge/sources/D003/requirements/ru.md`, §6.2.17 M1–M6; `docs-ref/knowledge/modules/geology/columns/output.md`; видео V007, 08:27–10:53. Это графический документ с дорожками, отдельный от реквизитов паспорта в БГД и паспорта результатов интерпретации Alpha.

Три шаблона меняют состав дорожек: керновая, бескерновая, гидрогеологическая. Источники литологии/руды, порядок дорожек, интервал, физический масштаб, цвет, сетка, легенда и реквизиты отражаются в предпросмотре. Масштаб экрана независим от масштаба документа. A3, альбомный: 180 мм по глубине на лист, длинные интервалы автоматически разбиваются без пропусков. Нажатие или Enter на дорожке открывает таблицу примеров; для гидрогеологических скважин сведения содержат журнал откачки.

Выдача: SVG, PNG/JPEG текущего листа, таблицы всего интервала в Excel XML Spreadsheet (`.xls`), печать всех листов и сохранение PDF средствами браузера. Поля браузера/колонтитулы отключаются пользователем в системном окне печати, масштаб 100%. Официальная форма компании не утверждена: оформление и все численные результаты подготовлены для демонстрации интерфейса, без расчётов запасов, интерпретации и интеграций.
