# UI Kit

Внутренняя библиотека `/team/ui-kit`, доступна третьим пунктом меню профиля после карты взаимосвязей. Доступна всем вошедшим профилям. Параметр `section` сохраняет категорию при перезагрузке и переходах истории; неизвестная категория открывает обзор. Страница загружается отдельно и использует собственную оболочку без продуктового меню.

Категории: обзор, цвета/поверхности, типографика, кнопки/статусы, поля/переключатели, навигация, окна, таблицы, обратная связь, карты/графики, рабочие области. Общие Button, Badge, Panel, Switch, Tooltip, WorkspaceTabs, WorkspaceDialog, DiscardChangesDialog, FilterPopover и RowActions подключены непосредственно из shared/ui. Карта и диаграммы используют существующие MapCanvas, MapObjectPopup и AnomalyLogChart. Нативные таблицы показывают несколько принятых способов компоновки.

Состояние примеров хранится только в React. Реестры и карточки не читают и не меняют хранилища БГД, паспортов или других модулей. CSV содержит текущую отфильтрованную таблицу примера. Пример БГД хранит изменения выбранных карточек до выхода из категории; диапазоны, координаты и селекты участвуют в проверке изменений. Сброс текущей категории выполняется через подтверждение.

Цвета темы считываются из CSS-переменных, предметные цвета - из `@kapgeo/geo-viz/tokens`. По брендбуку КАП (стр. 22) основные акценты: синий `#243D7C` (RGB 36/61/124) и оранжевый `#F7A700` (RGB 247/167/0); светлые подложки и hover-оттенки производные. Предметные цвета пород, слоёв и кривых остаются отдельной палитрой примеров.

По обновлению 06.11.2026 основной шрифт интерфейса - Segoe UI, первый резервный - Roboto, второй - Arial. Roboto Variable включён локально из [официального Google Fonts](https://github.com/google/fonts/tree/main/ofl/roboto); лицензия OFL находится рядом с файлом в `src/shared/assets/fonts/`. Отдельные font-face образцов Segoe UI, Roboto, Arial и Times New Roman показывают именно названную гарнитуру. Если она недоступна, карточка сообщает об этом. Утверждённые печатные формы сохраняют свою типографику. Знак взят из предоставленного мастер-файла `docs-ref/Logotip/лого2.png`; компонент показывает его символ через SVG viewBox без изменения пропорций оригинала.

Расширенная компоновка совмещает сводные карточки, реестр, вторую таблицу и каротаж; блоки независимо включаются переключателями. Лист документа - самостоятельный условный образец с масштабом просмотра и чёрно-белым режимом. Витрины компонентов также используются для иллюстраций документа дизайн-системы.
