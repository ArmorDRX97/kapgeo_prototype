# Информационная архитектура БГД

## Оболочка

Глобальная навигация расположена в шапке после логотипа и показывает только разрешённые модули. БГД и Геология являются отдельными пунктами: БГД открывает реализованную рабочую область, Геология — самостоятельную заглушку будущего модуля. Справа находятся поиск скважин, системные индикаторы и профиль; выход расположен внизу dropdown профиля. В БГД постоянная панель второго уровня объединяет выбор месторождения, его разделы и прокручиваемый список скважин. Сброс synthetic data вынесен в фиксированную плавающую кнопку. Переключателя Full/Minimum нет.

## Маршруты

| Маршрут | Назначение |
|---|---|
| `/` | redirect в домашний модуль активной персоны |
| `/auth/sign-in` | demo-вход |
| `/geology` | заглушка будущего геологического модуля |
| `/geology/bgd` | redirect в основные сведения текущего доступного месторождения; при отсутствии объектов — empty state |
| `/geology/bgd/:depositId?section=...` | карточка месторождения |
| `/geology/bgd/:depositId/wells/new?tab=...` | создание скважины |
| `/geology/bgd/:depositId/wells/:wellId?tab=...` | карточка скважины |
| `/technology` | заглушка технологического модуля |
| `/modeling` | заглушка моделирования |
| `/analytics` | заглушка аналитики |
| `/admin` | минимальное администрирование и создание месторождения |
| `/profile` | профиль и переключение 14 synthetic-ролей |

Недоступный по правам маршрут показывает forbidden-состояние, неизвестный — безопасное состояние 404.

## URL-состояние

Карточка месторождения хранит активный раздел в `section`. Карточка скважины хранит вкладку в `tab`. Deep link должен восстанавливаться после reload. Отдельного реестра месторождений в БГД нет: контекст меняется только селектором в постоянной панели второго уровня.

## Обязательные состояния

Loading, empty, repository error, not found, read-only, validation error, conflict version, success и destructive confirmation реализуются там, где применимо.
