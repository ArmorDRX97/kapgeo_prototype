# Информационная архитектура БГД

## Актуализация 12.10.2026 — реализация геологии

Решение пользователя о восстановлении геологии заменяет временное скрытие от 07.10, описанное ниже как история. Второй уровень: `/geology/sections` и `/geology/interpretation`. Старые `/geology?well=…` перенаправляются с контекстом; `/geology` без контекста открывает реестр. Интерпретационное хранение сохранено. Разрезы используют отдельный `kapgeo.sections.prototype.v1`, только локальные вымышленные источники и собственные ID; связь с БГД, перенос данных и legacy-миграция исключены пользователем.

Геолог и администратор редактируют разрезы; остальные пользователи с geology.view просматривают. Зафиксированный разрез read-only. Сценарий: реестр → сведения/профиль/скважины/карта → корреляция и ручная графика → сохранение → варианты чертежа. Несохранённый разрез защищает уход; незавершённая геометрия/исходные интервалы защищают смену режима. Save с ошибкой оставляет черновик; Save-and-continue выполняет переход только после успешной записи. Возврат из соседнего подмодуля восстанавливает выбранный разрез, режим и selection.

Пять заключительных задач согласованного автономного прототипа завершены 13.10.2026: удалены ритмопачки, добавлены соединение независимого сегмента профиля, произвольный состав локальных треков и выбор короткой/длинной дуги; выполнены заключительные QA и документация. Ручная литология, общие опоры и SVG/браузерная печать реализованы. Это ограниченный прототип, а не полное промышленное покрытие РП. См. [итог реализации](../../geo-module-refs/geology-implementation-report.md) и [матрицу](../../geo-module-refs/requirements-matrix.md).


## Оболочка

Решение пользователя 13.10.2026: подмодули геологии перенесены из страницы во второй ряд главного меню в `AppShell`, вне `main`. Дублирующего блока навигации нет. Реестр разрезов занимает весь левый край/высоту рабочей области (380 px на desktop), параметры фильтров открываются справа от кнопки поиска/фильтров. Разделы разреза — горизонтальный `WorkspaceTabs` над редактором, прежнее боковое меню удалено. Сохраняются URL/return-context/dirty guard; на узком экране прокручивается полоса вкладок и сворачивается реестр. [Устройство и QA](../task/geology-workspace-refresh.md).

Глобальная навигация расположена в шапке после логотипа и показывает только разрешённые модули. БГД и Геология являются отдельными пунктами: БГД открывает реализованную рабочую область, Геология — второй уровень разрезов и интерпретации (12.10.2026). Справа находятся поиск скважин, системные индикаторы и профиль; выход расположен внизу dropdown профиля. В БГД постоянная панель шириной 380 px содержит кнопку месторождения рядом со сворачиванием, напрямую открывающую общий просмотр, и прокручиваемый список скважин. В карточке скважины рядом расположено сгруппированное меню разделов шириной 240 px; справа — рабочая область с тематическими вкладками. Обе панели сворачиваются до узкой полосы. Сброс synthetic data вынесен в фиксированную плавающую кнопку. Переключателя Full/Minimum нет.

## Маршруты

| Маршрут | Назначение |
|---|---|
| `/` | redirect в домашний модуль активной персоны |
| `/auth/sign-in` | demo-вход |
| `/geology` (включая прежние параметры интерпретации) | временная заглушка геологического модуля |
| `/geology/bgd` | redirect в основные сведения текущего доступного месторождения; при отсутствии объектов — empty state |
| `/geology/bgd/:depositId` | общий просмотр месторождения; редактирование и смена объекта в диалогах |
| `/geology/bgd/:depositId/wells/new?tab=...` | создание скважины |
| `/geology/bgd/:depositId/wells/:wellId?tab=...` | карточка скважины |
| `/technology` | заглушка технологического модуля |
| `/modeling` | заглушка моделирования |
| `/analytics` | заглушка аналитики |
| `/admin` | минимальное администрирование и создание месторождения |
| `/profile` | профиль и переключение 14 synthetic-ролей |

Недоступный по правам маршрут показывает forbidden-состояние, неизвестный — безопасное состояние 404.

## URL-состояние

Общий просмотр месторождения не делится на вкладки; старый параметр `section` принимается для совместимости и не скрывает данные. Карточка скважины хранит раздел в `tab`, внутреннее представление — в `view` (валидируется для своего раздела). При смене скважины через список сохраняются оба значения; переходы между разделами доступны через Back/Forward. Deep link должен восстанавливаться после reload. Отдельного реестра месторождений в БГД нет: контекст меняется через «Сменить месторождение» в заголовке общего просмотра.

## Обязательные состояния

Loading, empty, repository error, not found, read-only, validation error, conflict version, success и destructive confirmation реализуются там, где применимо.

## Адаптивная навигация БГД

До 1180 px список скважин открывается кнопкой в шапке как выдвижная панель с backdrop, Escape и удержанием фокуса. До 700 px меню разделов располагается над рабочей областью и при первом открытии свёрнуто. Скважины, меню разделов и рабочая область имеют независимую прокрутку. Внутренние таблицы прокручиваются по горизонтали без расширения всей страницы.
