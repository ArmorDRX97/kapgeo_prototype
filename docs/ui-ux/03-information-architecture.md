# Информационная архитектура БГД

## Оболочка

Левое меню содержит только БГД, сброс synthetic data и профиль. Переключателя режима нет: БГД является единственной рабочей областью. Контекст, дата, глобальный поиск, фоновые задачи, уведомления и выход не открывают дополнительные области.

## Маршруты

| Маршрут | Назначение |
|---|---|
| `/` | redirect в `/geology/bgd` |
| `/auth/sign-in` | demo-вход |
| `/geology/bgd` | витрина месторождений |
| `/geology/bgd/:depositId?section=...` | карточка месторождения |
| `/geology/bgd/:depositId/wells/new?tab=...` | создание скважины |
| `/geology/bgd/:depositId/wells/:wellId?tab=...` | карточка скважины |
| `/profile` | закреплённый профиль геолога |

Неизвестный или удалённый маршрут показывает безопасное состояние 404 со ссылкой в БГД.

## URL-состояние

Карточка месторождения хранит активный раздел в `section`. Карточка скважины хранит вкладку в `tab`. Deep link должен восстанавливаться после reload.

## Обязательные состояния

Loading, empty, repository error, not found, read-only, validation error, conflict version, success и destructive confirmation реализуются там, где применимо.
