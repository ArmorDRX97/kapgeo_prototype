# Информационная архитектура БГД

## Оболочка

Глобальная навигация расположена в шапке после логотипа и показывает только разрешённые модули. БГД и Геология являются отдельными пунктами: БГД открывает реализованную рабочую область, Геология — временную заглушку (07.10.2026); рабочее место интерпретации сохранено в исходниках. Справа находятся поиск скважин, системные индикаторы и профиль; выход расположен внизу dropdown профиля. В БГД постоянная панель шириной 380 px содержит компактное название месторождения с выпадающим меню разделов/редактирования/смены объекта и прокручиваемый список скважин. В карточке скважины рядом расположено сгруппированное меню разделов шириной 240 px; справа — рабочая область с тематическими вкладками. Обе панели сворачиваются до узкой полосы. Сброс synthetic data вынесен в фиксированную плавающую кнопку. Переключателя Full/Minimum нет.

## Маршруты

| Маршрут | Назначение |
|---|---|
| `/` | redirect в домашний модуль активной персоны |
| `/auth/sign-in` | demo-вход |
| `/geology` (включая прежние параметры интерпретации) | временная заглушка геологического модуля |
| `/geology/bgd` | redirect в основные сведения текущего доступного месторождения; при отсутствии объектов — empty state |
| `/geology/bgd/:depositId?section=...` | карточка месторождения |
| `/geology/bgd/:depositId/wells/new?tab=...` | создание скважины |
| `/geology/bgd/:depositId/wells/:wellId?tab=...` | карточка скважины |
| `/technology` | заглушка технологического модуля |
| `/modeling` | заглушка моделирования |
| `/analytics` | заглушка аналитики |
| `/admin` | минимальное администрирование и создание месторождения |
| `/profile` | профиль и переключение 14 synthetic-ролей |

Недоступный по правам маршрут показывает forbidden-состояние, неизвестный — безопасное состояние 404.

## URL-состояние

Карточка месторождения хранит активный раздел в `section`. Карточка скважины хранит раздел в `tab`, внутреннее представление — в `view` (валидируется для своего раздела). При смене скважины через список сохраняются оба значения; переходы между разделами доступны через Back/Forward. Deep link должен восстанавливаться после reload. Отдельного реестра месторождений в БГД нет: контекст меняется только селектором в постоянной панели второго уровня.

## Обязательные состояния

Loading, empty, repository error, not found, read-only, validation error, conflict version, success и destructive confirmation реализуются там, где применимо.

## Адаптивная навигация БГД

До 1180 px список скважин открывается кнопкой в шапке как выдвижная панель с backdrop, Escape и удержанием фокуса. До 700 px меню разделов располагается над рабочей областью и при первом открытии свёрнуто. Скважины, меню разделов и рабочая область имеют независимую прокрутку. Внутренние таблицы прокручиваются по горизонтали без расширения всей страницы.
