Четыре независимых контекста int-demo-01…04 сохранены; новые ГК/КС/ПС/ТК/ИК/ТМ/КМ/КМр/РМ и повторы детерминированы в alphaFixtures, без реальных измерений. Исходники отдельно от derived-записей, nullable gaps сохранены. Новый документ хранится в kapgeo.alpha.interpretation.v1; старый namespace керна/интерпретации остаётся самостоятельным. [Состав рабочего этапа](../../geo-module-refs/Interpretation/implementation-stage-1.md).

Все данные детерминированы и явно демонстрационные.

- исходные месторождения и скважины создаются seed-функциями;
- эталонная полностью заполненная скважина — `WELL-1010-FULL`;
- пользовательские изменения сохраняются в IndexedDB;
- записи версий и audit events создаются вместе с предметными mutation;
- общий сброс удаляет локальные изменения и восстанавливает seed;
- реальные производственные данные, credentials и сетевые интеграции запрещены.

## Автономный набор интерпретации

По уточнению пользователя от 05.10.2026 данные интерпретации полностью отдельные от БГД. `src/entities/interpretation/model/fixtures.ts` содержит DEMO-101 (редактируемый пример), DEMO-102 (зафиксированный), DEMO-103 (без каротажа/керна), DEMO-104 (версия соответствия fixture-v1 при источнике fixture-v2). Учебное месторождение «Песчаный» — контекст этой демонстрации, не запись каталога БГД.

Глубина 160 м, рабочее окно 112–136 м. Три кривые КС/ГК по 1601 точке с шагом 0,1 м и пропуском КС. Три согласованных рейса: 3 керновых и 2 исходных бескерновых сегмента. Шесть проб: 3 КП (одна составная), по одной ГС/ЛГХ/ТП. Цвета и мощности исходной литологии согласованы с выходом. Лаборатория — общий вымышленный процент для демонстрации сохранения анализа, не предметная схема всех материалов.

Изменения сохраняются в отдельном localStorage `kapgeo.interpretation.demo.v1:<wellId>`, с Zod-проверкой и конфликтом ревизий. Сброс в панели интерпретации затрагивает только выбранную demo-скважину. Общий IndexedDB reset не управляет этим namespace. Копирование БГД-объектов, production data и API не требуется.

## Демонстрационный реестр разрезов — 13.10.2026

Общий GTR-01 имеет preset `video-reference-v1`: семь скважин, профиль около 350 м, Z −442…−535 м, переменные траектории/забои/каротажи; согласованные технологические, рудные и литологические интервалы. `referenceSources.ts` содержит детерминированные источники, `referenceSection.ts` — связи, ручные области/исключения, линии и два чертежа. Реальные измерения/идентификаторы из видео не копируются. `sourceFor`/`sectionSources` выбирают preset перед локальными overrides; новые самостоятельные документы сохраняют базовые источники.

`demoList` обновляет только прежний GTR-01 при первом входе и сохраняет предыдущий записанный документ в `kapgeo.sections.previous-demo.v1`. Имя/статус сохраняются, ревизия увеличивается. Повторные открытия не сбрасывают правки; удалённый документ не восстанавливается. Ошибка записи или невалидный реестр не заменяют сохранения. Набор данных и точная визуальная трассировка — в [отчёте реконструкции](../../geo-module-refs/reference-reconstruction.md).

По прямому запросу пользователя начальный реестр геологии показывает 200 строк с разными названиями: исходные GTR-01/GTR-02 и 198 лёгких записей GTR-DEMO-3…200. Все 199 незаблокированных начальных строк ссылаются на один документ GTR-01; профиль 02 сохраняет отдельный GTR-02 с locked. Названия и ID строк — оформление списка; самостоятельных наборов скважин/графики/чертежей у алиасов нет. `sectionRegistryEntries` создаёт только метаданные реестра в памяти, не записывает их в localStorage. Save из любого алиаса меняет общий документ; JSON и заголовок показывают идентичность этого документа. ID выбранной строки сохраняется в URL и подсветке при переключении вкладок/reload. Созданные вручную документы остаются независимыми и увеличивают число строк сверх начальных 200. При удалении GTR-01 исчезают его демонстрационные ссылки. Связей с БГД/интерпретацией нет.
