# Synthetic data БГД

Все данные детерминированы и явно демонстрационные.

- исходные месторождения и скважины создаются seed-функциями;
- эталонная полностью заполненная скважина — `WELL-1010-FULL`;
- пользовательские изменения сохраняются в IndexedDB;
- записи версий и audit events создаются вместе с предметными mutation;
- общий сброс удаляет локальные изменения и восстанавливает seed;
- реальные производственные данные, credentials и сетевые интеграции запрещены.

## Автономный набор интерпретации

По уточнению пользователя от 05.10.2026 данные интерпретации полностью отдельные от БГД. `src/entities/interpretation/model/fixtures.ts` содержит DEMO-101 (редактируемый пример), DEMO-102 (зафиксированный), DEMO-103 (без каротажа/керна), DEMO-104 (версия соответствия fixture-v1 при источнике fixture-v2). Учебное месторождение «Песчаный» — контекст этой демонстрации, не запись каталога БГД.

Глубина 160 м, рабочее окно 112–136 м. Три кривые КС/ГК по 1601 точке с шагом 0,1 м и пропуском КС. Три согласованных рейса: 3 керновых и 2 исходных бескерновых сегмента. Шесть проб: 3 КП (одна составная), по одной ГС/ЛГХ/ТП. Цвета и мощности исходной литологии согласованы с выходом. Лаборатория — общий вымышленный процент для демонстрации сохранения анализа, не предметная схема всех материалов.

Изменения сохраняются в отдельном localStorage `kapgeo.interpretation.demo.v1:<wellId>`, с Zod-проверкой и конфликтом ревизий. Сброс в панели интерпретации затрагивает только выбранную demo-скважину. Общий IndexedDB reset не управляет этим namespace. Копирование БГД-объектов, production data и API не требуется.
