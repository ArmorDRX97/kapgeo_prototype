# Сквозные сценарии БГД

## Вход и выбор месторождения

`Вход → БГД → основные сведения текущего месторождения → при необходимости сменить контекст в панели → открыть раздел или скважину`

## Работа с месторождением

`Основные сведения → участки и залежи → кондиционные лимиты → скважины → редактирование`

Активный раздел записывается в URL. Создание новой версии кондиций не изменяет утверждённую версию до явного утверждения.

Переход по пункту «БГД» в глобальной шапке открывает основные сведения текущего доступного месторождения. Пункт «Геология» открывает автономное рабочее место интерпретации. Кнопок возврата к реестру и явного назначения текущего объекта в карточке нет.

## Работа со скважиной

`Постоянный список скважин → найти/отфильтровать → создать/открыть → тематическая вкладка → валидация → сохранить → новая версия и audit event`

`Скважина → Инклинометрия → выбрать/добавить промер → заполнить точки → сохранить → рассчитать dX/dY/dZ и R/UK/AK → назначить основной промер`

`Выбрать строку промера → Удалить → подтвердить удаление описания и результатов измерений`; для основного промера подтверждение отдельно предупреждает об отсутствии основного набора и невозможности расчёта геометрии ствола.

Production-импорт инклинометрии является отдельным будущим сценарием. Текущая модалка демонстрирует его структуру только на явно маркированном synthetic fixture.

## Роль и модули

`Профиль → сменить synthetic-роль → пересчитать разрешённые модули → перейти в домашнюю область роли`

`Администратор R13 → Администрирование → Создать месторождение → объект появляется в БГД`

## Справочные данные

`Администрирование → Справочники → таб Все/Обычные/Reff → строка-карточка справочника → выбрать запись в постоянной правой панели → изменить поля в одну колонку → валидация → сохранить → новая версия и audit`. До выбора справочника правая панель остаётся видимой с подсказкой; смена объекта с несохранённым вводом требует подтверждения.

`Выбранная запись → деактивировать → подтвердить → исключение из нового выбора, сохранение исторических связей`; повторная активация возвращает запись в выбор. Удаление допускается только без связанных данных и после подтверждения.

Раздел автономный: его вымышленные записи не используются в БГД, инклинометрии или других модулях. Связи и запрет удаления проверяются только между записями самого каталога.

`Правая панель справочника → История → только история всего справочника → Закрыть историю → прежняя форма и черновик`. Переключение не сбрасывает введённые значения.

## Сброс демо-среды

`Плавающая кнопка или error boundary → подтверждение → очистка IndexedDB и in-memory seed → reload`

Переходы в технологию, моделирование и аналитику ведут на честные заглушки без декоративных неработающих действий. Сброс интерпретации выполняется отдельно в её панели и затрагивает только выбранную demo-скважину.

## Автономная интерпретация

`Геология → DEMO-101 → Литология → выбрать интервал на колонке или в таблице → изменить границы/породу → Применить → Отменить/Повторить → Сохранить → reload восстанавливает результат`.

`Технологические интервалы → Рассчитать по КС → метод потенциал/градиент, источник, диапазон, порог, отдельные минимумы, округление, направление → Рассчитать → отдельная колонка предпросмотра → скорректировать → Применить результат → подтвердить замену всех интервалов → Сохранить`. Изменение параметров требует пересчёта; отмена предпросмотра сохраняет текущий результат.

`Привязка керна → выбрать сегмент → привязка/split/merge/мощность/контакт/вставка/перестановка/свойства/операция рейса → применить → литология, промер и части проб меняются вместе → undo возвращает весь результат`. Удалённый исходный сегмент остаётся нулевым в реестре → Восстановить сегмент → вернуть исходную мощность и связи. Вставленный бескерновый удаляется полностью, обычный undo возвращает его.

`Вид проб КП/ГС/ЛГХ/ТП → выбрать часть / создать диапазон → номер, глубины, мощность → Применить пробу → обратный расчёт исходных глубин и обрезка перекрытых частей того же вида → Save`. Другие виды и лабораторные значения сохраняются.

`Устаревшее соответствие → Восстановить соответствие / К буровой колонке → подтвердить сброс сводных правок/проб и истории → новая модель по исходным данным → Save`. Reset не входит в undo. Промышленная интеграция с БГД — будущий сценарий; этот набор не меняет БГД.

При смене demo-скважины или уходе с несохранёнными изменениями/предпросмотром пользователь подтверждает их отбрасывание либо остаётся. Перед сохранением незавершённую форму и расчёт нужно применить или отменить.
