# Сквозные сценарии БГД

## Вход и выбор месторождения

`Вход → витрина БГД → выбрать месторождение → открыть карточку`

## Работа с месторождением

`Основные сведения → участки и залежи → кондиционные лимиты → скважины → редактирование`

Активный раздел записывается в URL. Создание новой версии кондиций не изменяет утверждённую версию до явного утверждения.

## Работа со скважиной

`Карточка месторождения → Скважины → создать/открыть → тематическая вкладка → валидация → сохранить → новая версия и audit event`

## Сброс

`Меню или error boundary → подтверждение → очистка IndexedDB и in-memory seed → reload`

Межмодульных переходов в текущей ветке нет.
