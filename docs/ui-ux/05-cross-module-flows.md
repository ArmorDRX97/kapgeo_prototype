# Сквозные сценарии БГД

## Вход и выбор месторождения

`Вход → геологический модуль → основные сведения текущего месторождения → при необходимости сменить контекст в панели → открыть раздел или скважину`

## Работа с месторождением

`Основные сведения → участки и залежи → кондиционные лимиты → скважины → редактирование`

Активный раздел записывается в URL. Создание новой версии кондиций не изменяет утверждённую версию до явного утверждения.

Переход по пункту «Геология» в глобальной шапке открывает основные сведения текущего доступного месторождения. Кнопок возврата к реестру и явного назначения текущего объекта в карточке нет.

## Работа со скважиной

`Постоянный список скважин → найти/отфильтровать → создать/открыть → тематическая вкладка → валидация → сохранить → новая версия и audit event`

## Роль и модули

`Профиль → сменить synthetic-роль → пересчитать разрешённые модули → перейти в домашнюю область роли`

`Администратор R13 → Администрирование → Создать месторождение → объект появляется в БГД`

## Сброс

`Плавающая кнопка или error boundary → подтверждение → очистка IndexedDB и in-memory seed → reload`

Переходы в будущие модули ведут на честные заглушки без декоративных неработающих действий.
