# Сквозные сценарии БГД

## Разрезы: применение и печать — 15.10.2026

`Создать разрез → реквизиты блоков → линия сегмента (preview/Apply или Cancel) → выбор и порядок скважин → карта/коридор → графические команды → Save → вариант чертежа → состав скважин/колонок/слоёв → SVG/PNG/печать`. Неприменённые диалоги и двухкликовая опора сообщают о pending-геометрии. Все применённые команды используют общую историю. БГД/Alpha/план не получают геологических мутаций этого сценария. [Подробности](../task/sections-design-pdf-2026-10-15.md).


## Возврат из внутреннего инструмента — 14.10.2026

`Рабочий экран → профиль → Карта взаимосвязей (для команды) → исследование/обучение → В прототип → исходный route/query`. Это только навигационный переход: учебные понятия не читают и не изменяют производственные записи, выбор объекта БГД не переносится в модель атласа. Полный внутренний flow описан [отдельно](../../src/internal/knowledge-map/README.md).

## Карта/разрез: уточнённые локальные сценарии — 14.10.2026

План: `проект → блок → точка → выбрать/подвести к существующему забою либо устью → Применить → Сохранить → reload`. Скважина остаётся неподвижной; ссылка сохраняется, Undo/Redo включает привязку, свободный ввод требует явной отвязки. Профиль карты имеет собственные сегменты/состав без связи с документом разреза. Старые сохранения мигрируют в памяти, пользовательские изменения/удаления остаются, запись по Save.

Разрез: `документ → этап изучения/тип → профиль → рабочий сегмент → назначить существующие скважины → увидеть проекцию → Save/reload`. Общая вершина влияет на два сегмента; разворот сохраняет связи, удаление/разбиение исчезнувшего ребра предупреждает о снятии назначений. Удаление сегмента и выравнивание карты проверяют ручную геометрию/чертежи; исключение скважины подтверждается и корректирует её локальные связи, исходную скважину не удаляет. Контакты руды/технологии/забаланса вычисляются по своим исходным интервалам, продление меняет только контур. Межмодульных записей нет. [Решения/QA](../../geo-module-refs/VideoAudit-2026-10-14/implementation-report.md).

## Интерактивный план: самостоятельный flow — 14.10.2026

`Геология → Интерактивный план месторождения → проект → слой/объект → инструмент → черновик → Применить → Сохранить план → SVG/PNG/печать`. Реестр и карта работают с собственными ID/хранилищем. Выбор и return-context отражаются в URL/сессии; переход к только что применённому объекту внутренний и не запускает dirty guard. Уход к другому проекту/модулю защищён Stay/Discard/Save, незавершённая операция требует завершения. Повреждённое хранилище не заменяется молча; доступны backup/retry/явный reset только карты.

Реальные переходы/записи в БГД, разрезы и интерпретацию не создавались. Их namespace, состояние и результаты не меняются. Геолог/администратор с map permission, scope и unlocked редактирует; остальные geology.view просматривают и временно переключают видимость. [Полное поведение](../../geo-module-refs/InteractivePlan/implementation-report.md).

## Переходы через меню модулей — 14.10.2026

`Шапка → Геология → Разрезы и развертки / Интерпретация / Интерактивный план месторождения`. Открытие dropdown и нажатие пустого пункта не являются переходом и не меняют ввод/данные/URL. Рабочая ссылка сохраняет прежние guards; Stay оставляет ввод, Discard/Save относятся к текущему рабочему документу. Контекст возврата записывается при закрытом меню; menu close после реального перехода/Back не сбрасывает выбранные объекты. Геотехнология имеет восемь кнопок-пустышек с обратной связью. Режимы, namespace и ACL прежние. [Решение/QA](../task/module-menu-refresh.md).


## Интерпретация Альфа: итоговые правила переходов — 13.10.2026

`Запись → параметры → Calculate → preview → Apply → Save`. Расчёт сначала применяет валидные параметры к рабочему документу. «Отменить предпросмотр» отбрасывает новый результат, сохраняя эти параметры; прежний результат остаётся stale. Undo возвращает применённые параметры. Отдельный «Отменить параметры» отменяет ещё не применённый ввод.

Методы одной скважины разделяют применённый рабочий документ. Свободный переход между ними сохраняет его; незавершённая форма/preview требует Stay или отмены этого ввода. Смена выбора с незавершёнными свойствами тоже защищена; Cancel не вызывает повторное предупреждение. Переход в другую скважину, керн/пробы или модуль защищает весь несохранённый документ с Stay/Save/Discard. URL from/to сохраняется при смене методов/скважин, Back/Forward работает. Save запрещён при незавершённом вводе/preview; ошибка записи удерживает переход.

`ЭК/ТК → stale ГК`, `ТК → stale КМр/РМ`, `ЭК → stale РМ по литологии`, `профиль ГК → stale производственного контроля`. Выбор производной записи явный; её ревизия инвалидирует использующие её результаты. Секции покрывают текущий фактический фильтр. Предложение фильтра ГК не изменяет факт ТК. Реквизиты не влияют на расчёты. Виды/подписи сохраняются отдельно и не входят в историю документа; паспорт берёт соответствующие шкалы/стили/подписи методов.

Сценарии, доступы и старые хранилища проверены в [итоговой приёмке](../../geo-module-refs/Interpretation/implementation-acceptance.md). Ранние этапы ниже — история уточнений.


## Интерпретация Альфа, рабочий этап 1 — 13.10.2026

Скважина → метод → запись/параметры → Рассчитать → preview → Применить → Save → reload. Переход между методами сохраняет общий черновик; незавершённый preview и уход к другой скважине защищены. ЭК/ТК питают окончательную ГК, фильтр — КМр/РМ; изменение зависимостей помечает результат устаревшим. Производная кривая не заменяет исходник. КНД-м — заглушка. Керн/пробы имеют отдельное сохранение и доступны через «Дополнительно». Из разрезов восстанавливаются метод/скважина. [Границы](../../geo-module-refs/Interpretation/implementation-stage-1.md).

## Общий пример по кадрам видео — 13.10.2026

Первый вход в реестр → обновление прежнего GTR-01 с резервированием сохранённой версии → любая общая строка реестра → один готовый пример с семью скважинами → графические разделы/карта/два чертежа. Выбор объекта и drag узла меняют действительную геометрию; Apply/Save/Undo и reload используют прежний сценарий. В связанной стороне интервала редактируются дуги; после разъединения доступны точки выклинивания. SVG/PNG и print media строятся из тех же данных. Повторный вход не сбрасывает сохранённые правки preset; независимые документы и locked-пример не обновляются. Связей с БГД/интерпретацией нет. [Данные, источники и проверка](../../geo-module-refs/reference-reconstruction.md).

## Настройка во вкладке «Разрез» — 13.10.2026

Выбор строки реестра → «Разрез» → параметры/вершины профиля/включение скважин в одном черновике → карта или графические построения → общий Save → reload. Изменение профиля сразу отражается в таблице скважин, устаревший preview подбора по коридору больше не предлагается к применению. Расчёт профиля и оформление раскрываются в своих блоках. Смена вкладки этого документа сохраняет черновик, включая выбранные GTR-DEMO-ссылки; смена строки/модуля вызывает прежнюю защиту. Legacy-ссылки «Профиль» и «Скважины» открывают общую вкладку. Locked и пользователь без edit-permission видят те же блоки без возможности изменения.

## Демонстрационный реестр разрезов — 13.10.2026

200 начальных строк → выбор любой из 199 общих ссылок → один документ GTR-01 → переключение вкладок сохраняет ID выбранной строки → Save записывает общий документ → другая ссылка показывает те же сохранённые данные. Профиль 02 ведёт в отдельный зафиксированный GTR-02. Reload/Back восстанавливают строку и фильтры из URL. Создание нового разреза сохраняет прежний независимый сценарий. Это демонстрационное увеличение списка по запросу пользователя, а не 200 независимых документов.

## Общая шапка разреза — 13.10.2026

`Правка в любой вкладке → Не сохранено → Save вверху справа → Сохранено`. Неприменённые правки текущего редактора показывают «Правки не применены» и требуют прежнего Apply/Cancel перед Save. JSON/Undo/Redo и Save относятся ко всему выбранному разрезу, остаются доступны при скрытой панели инструментов. Общий статус не дублируется generic-уведомлением после commit/Save. Undo/Redo или последствия коррекции могут иметь отдельное описание в шапке/сведениях. Общие ошибки и stale-opоры видны над вкладками; draft/guards/permissions сохранены.

## Сворачиваемые инструменты и справка — 13.10.2026

`Выбрать графический раздел → Работа с объектами → выбрать/создать объект → Координаты точек или drag узла → проверить preview → Применить геометрию → Save`. Переключение/сворачивание блоков только меняет видимость и сохраняет ввод/pending; начало drag раскрывает координаты без остановки жеста. «Отображение» содержит экран/колонки либо параметры листа, операции объектов и экспорт находятся в блоке объектов. Apply/Cancel ручной геометрии доступны вне блоков, в том числе когда все свёрнуты. Ошибка ручной геометрии/корреляции/компоновки видима независимо от открытого блока. `Как работать → общее окно управления → Escape/закрыть → возврат фокуса` сохраняет черновик. На mobile прокручивается содержимое выбранного блока в ограниченной области; общая горизонтальная прокрутка не добавляется.

## Центральная графика и правая панель — 13.10.2026

`Выбрать разрез слева → графический раздел сверху → выбрать/настроить объект справа → drag/выбор на центральном графике → проверить правый редактор → Apply → Save`. Save/Undo/Redo/JSON и сообщения расположены справа; перемещение/zoom сохраняют прежние жесты. Инструменты прокручиваются отдельно от графики. Свернуть правую панель → продолжить работу на увеличенном графике → развернуть возвращает тот же ввод/selection; это не отмена и не сохранение. Предпросмотр замкнутой дуги временно заменяет основной центральный график до Apply/Cancel. Карта и чертёж используют тот же центр и собственный набор инструментов справа. На узком экране панель располагается ниже графика без наложения; активная верхняя вкладка раскрывается прокруткой полосы после resize. Dirty-guards, роль/permission/scope/status, Undo/Redo и локальное хранение сохранены.

## Ручная геометрия разреза — 13.10.2026

`Литология / Зона окисления → выбрать объект или исключение → Перемещение и точки → drag узла → валидный preview + таблица → Применить геометрию → Undo/Redo → Сохранить разрез → reload`. Фон перемещает камеру и не меняет точки; «Добавлять точки» явно переключает ЛКМ на построение. Escape в активном drag возвращает состояние до жеста, включая ранее введённые табличные правки. Недопустимая конечная геометрия также откатывает только жест и показывает причину. Незавершённый черновик защищает смену режима/подмодуля; «Остаться» сохраняет ввод. Read-only имеет прежний просмотр/навигацию без ручек редактирования. Заголовки скважин/треков располагаются над рамкой и следуют за колонками по X независимо от вертикального pan. [Технический отчёт](../task/geology-workspace-refresh.md#прямое-редактирование-точек-и-внешние-заголовки--13102026).

## Актуализация 12.10.2026 — реализация геологии

Решение пользователя о восстановлении геологии заменяет временное скрытие от 07.10, описанное ниже как история. Второй уровень: `/geology/sections` и `/geology/interpretation`. Старые `/geology?well=…` перенаправляются с контекстом; `/geology` без контекста открывает реестр. Интерпретационное хранение сохранено. Разрезы используют отдельный `kapgeo.sections.prototype.v1`, только локальные вымышленные источники и собственные ID; связь с БГД, перенос данных и legacy-миграция исключены пользователем.

Геолог и администратор редактируют разрезы; остальные пользователи с geology.view просматривают. Зафиксированный разрез read-only. Сценарий: реестр → сведения/профиль/скважины/карта → корреляция и ручная графика → сохранение → варианты чертежа. Несохранённый разрез защищает уход; незавершённая геометрия/исходные интервалы защищают смену режима. Save с ошибкой оставляет черновик; Save-and-continue выполняет переход только после успешной записи. Возврат из соседнего подмодуля восстанавливает выбранный разрез, режим и selection.

Пять заключительных задач согласованного автономного прототипа завершены 13.10.2026: удалены ритмопачки, добавлены соединение независимого сегмента профиля, произвольный состав локальных треков и выбор короткой/длинной дуги; выполнены заключительные QA и документация. Ручная литология, общие опоры и SVG/браузерная печать реализованы. Это ограниченный прототип, а не полное промышленное покрытие РП. См. [итог реализации](../../geo-module-refs/geology-implementation-report.md) и [матрицу](../../geo-module-refs/requirements-matrix.md).


## Образовательный атлас — 09.10.2026

В отдельном Knowledge Map пользователь проходит `общий обзор → область → процесс/объект → объяснение → связанные понятия`. Поиск открывает выбранное понятие; фокус оставляет соседей на один или два шага; исследование пути объясняет цепочку без искусственного прохода через учебные группы. «Специалисты», «Данные» и «Модули KAPGEO» меняют проекцию той же модели. Учебные маршруты поддерживают шаг назад/вперёд, приостановку и локальное продолжение.

Это самостоятельный образовательный сценарий. Связи геологических, технологических и учётных процессов объясняют предметную область; они не добавляют рабочие интеграции или переходы в основной прототип. Реализация и границы модулей указаны отдельно в их карточках. Сценарии БГД ниже сохранены.

**Временное ограничение 07.10.2026:** переход в «Геологию» и прежние ссылки `/geology?...` открывают заглушку. Описанные ниже сценарии автономной интерпретации сохранены как спецификация скрытой реализации, но сейчас недоступны через интерфейс. Сценарии БГД продолжают работать.

## Массовое заполнение интервалов бурения

БГД → скважина → Проходка и освоение → Проходка → Добавить интервалы → 1/5/10/20 → заполнить пять полей каждой строки → удалить лишние строки по одной / Удалить пустые → Сохранить изменения.

Новые строки пустые, фокус находится в первом новом диаметре; Tab проходит поля в порядке строки. Массовая очистка сохраняет любую частично заполненную строку. Все оставшиеся строки проходят прежнюю предметную валидацию и сохраняются вместе с карточкой. Без разрешения на редактирование добавление, заполнение и удаление недоступны.

## Вход и выбор месторождения

`Вход → БГД → общий просмотр текущего месторождения → при необходимости «Сменить месторождение» в заголовке → открыть скважину`

Кнопка месторождения рядом со сворачиванием левой панели сразу открывает общий экран. «Сменить месторождение» справа от заголовка открывает диалог доступных объектов; выбор сохраняет текущий объект в настройках и затем меняет маршрут. Ошибка записи оставляет диалог открытым без перехода. Отменить / Escape / закрытие возвращают к просмотру.

## Работа с месторождением

`Общий экран со всеми данными → при необходимости «Редактировать» в заголовке → изменить поля → Сохранить изменения → обновлённый просмотр`

Названия и описания RU/KZ/EN, сведения, независимые таблицы участков и залежей, а также доступный аудит видны на странице месторождения без вкладок. Действие «Кондиционные лимиты» между «Редактировать» и «Сменить месторождение» открывает отдельную страницу этого объекта. На ней сохранена карточка значений в два столбца и действие «Изменить». Сохранение закрывает редактор и записывает единый набор; отмена / Escape / клик вне окна закрывают без записи. При каждом открытии набор сразу редактируется при наличии прав; версий, утверждения и публикации нет. Отсутствие участков не препятствует работе с лимитами. Параметр границы вечной мерзлоты исключён.

Переход по пункту «БГД» в глобальной шапке открывает общий просмотр текущего доступного месторождения. Пункт «Геология» временно открывает заглушку (07.10.2026). Кнопок возврата к реестру и явного назначения текущего объекта в карточке нет.

Для участков и залежей: кнопка добавления в заголовке или троеточие строки → Редактировать → форма → Сохранить / Отменить. Троеточие → Удалить → подтверждение → запись исчезает из таблицы; зависимость залежи от скважин блокирует удаление с объяснением. Участки и залежи месторождения ведутся независимо. Редактор месторождения содержит только его сведения, языковые поля сгруппированы попарно. Список скважин доступен только слева.

## Работа со скважиной

`Постоянный список скважин → найти/отфильтровать → создать/открыть → группа и раздел в соседнем меню → вкладка рабочей области → валидация → сохранить текущие значения → audit event`

`Открытый раздел и view → другая скважина в списке → тот же раздел и view новой скважины`. Формы и выбор независимых workspace пересоздаются для нового объекта.

Смена скважины, раздела карточки или внутренней вкладки при несохранённом вводе вызывает диалог «Остаться / Отменить изменения и перейти / Сохранить и перейти». Сохранение проходит предметную валидацию и должно завершиться до перехода; при ошибке остаются текущая вкладка и введённые значения. Отмена изменений восстанавливает сохранённое состояние. Закрытие вкладки браузера с несохранённым вводом использует стандартное beforeunload-предупреждение. БГД сохраняет текущие значения без номеров версий и снимков записей.

`Скважина → Инклинометрия → выбрать/добавить промер → заполнить точки → сохранить → рассчитать dX/dY/dZ и R/UK/AK → назначить основной промер`

`Выбрать строку промера → Удалить → подтвердить удаление описания и результатов измерений`; для основного промера подтверждение отдельно предупреждает об отсутствии основного набора и невозможности расчёта геометрии ствола.

Production-импорт инклинометрии является отдельным будущим сценарием. Текущая модалка показывает структуру на детерминированном fixture; видимые пометки сняты по прямому решению пользователя, произвольные файлы по-прежнему не разбираются.

`Администратор R13 → Администрирование → Создать месторождение → объект появляется в БГД`

## Справочные данные

`Администрирование → Справочники → таб Все/Обычные/Reff → строка-карточка справочника → выбрать запись в постоянной правой панели → изменить поля в одну колонку → валидация → сохранить → новая версия и audit`. До выбора справочника правая панель остаётся видимой с подсказкой; смена объекта с несохранённым вводом требует подтверждения.

`Выбранная запись → деактивировать → подтвердить → исключение из нового выбора, сохранение исторических связей`; повторная активация возвращает запись в выбор. Удаление допускается только без связанных данных и после подтверждения.

Раздел автономный: его вымышленные записи не используются в БГД, инклинометрии или других модулях. Связи и запрет удаления проверяются только между записями самого каталога.

`Правая панель справочника → История → только история всего справочника → Закрыть историю → прежняя форма и черновик`. Переключение не сбрасывает введённые значения.

## Сброс демо-среды

`Профиль и роли → нижняя карточка «Сброс демо-данных» → Сбросить демо-данные → очистка IndexedDB, in-memory seed и query cache → завершение сессии → авторизация`. Кнопка доступна прямо в карточке, без выпадающего меню и дополнительного подтверждения. Ошибка сброса оставляет сессию активной и позволяет повторить действие. Аварийный сброс из error boundary остаётся отдельным механизмом восстановления.

Переходы в технологию, моделирование и аналитику ведут на честные заглушки без декоративных неработающих действий. Сброс интерпретации выполняется отдельно в её панели и затрагивает только выбранную demo-скважину.

## Автономная интерпретация

`Геология → DEMO-101 → Литология → выбрать интервал на колонке или в таблице → изменить границы/породу → Применить → Отменить/Повторить → Сохранить → reload восстанавливает результат`.

`Технологические интервалы → Рассчитать по КС → метод потенциал/градиент, источник, диапазон, порог, отдельные минимумы, округление, направление → Рассчитать → отдельная колонка предпросмотра → скорректировать → Применить результат → подтвердить замену всех интервалов → Сохранить`. Изменение параметров требует пересчёта; отмена предпросмотра сохраняет текущий результат.

`Привязка керна → выбрать сегмент → привязка/split/merge/мощность/контакт/вставка/перестановка/свойства/операция рейса → применить → литология, промер и части проб меняются вместе → undo возвращает весь результат`. Удалённый исходный сегмент остаётся нулевым в реестре → Восстановить сегмент → вернуть исходную мощность и связи. Вставленный бескерновый удаляется полностью, обычный undo возвращает его.

`Вид проб КП/ГС/ЛГХ/ТП → выбрать часть / создать диапазон → номер, глубины, мощность → Применить пробу → обратный расчёт исходных глубин и обрезка перекрытых частей того же вида → Save`. Другие виды и лабораторные значения сохраняются.

`Устаревшее соответствие → Восстановить соответствие / К буровой колонке → подтвердить сброс сводных правок/проб и истории → новая модель по исходным данным → Save`. Reset не входит в undo. Промышленная интеграция с БГД — будущий сценарий; этот набор не меняет БГД.

При смене demo-скважины или уходе с несохранёнными изменениями/предпросмотром пользователь подтверждает их отбрасывание либо остаётся. Перед сохранением незавершённую форму и расчёт нужно применить или отменить.


### Ручная литология разреза — принято 12.10.2026

`Разрез → Литология → Добавить область → упорядоченные точки X/Z и порода → Применить → Внутреннее исключение → точки → Применить → Сохранить → reload`. Черновик защищает уход и отменяется Escape; общий Undo/Redo действует на применённую геометрию. Исключение прозрачно, строго внутри родителя, без пересечения соседних исключений. Правка родителя проверяет все дочерние контуры; удаление родителя перечисляет число исключений и выполняется одной отменяемой командой после подтверждения. Окисление привязывается к колонкам и ручным границам с видимой подсказкой. Автоматическая межскважинная корреляция пород не входит в согласованный прототип.


### Дополнение реализации — 12.10.2026

Новый профиль на карте задаётся двумя кликами и заменяет трассу только после preview/validation/Apply. Состав скважин сохраняется; опасное сокращение с зависимыми областями/чертежом блокируется. Частичный жест защищает уход, Escape отменяет. В режиме добавления скважин click или Tab/Enter включает скважину без изменения трассы и участия в слоях.

Выбранный исходный интервал показывает маркеры выклинивания, граничных контактов и узлов связанных дуг. Drag/стрелки используют существующие численные ограничения: исходные контакты фиксированы, boundary только по Z, остальные — между соседними опорами, дуги не пересекаются. Один завершённый жест — одна команда Undo; Escape отменяет preview. Численные формы остаются альтернативой. Маркеры отсутствуют в clean-чертежах и read-only.

Настройки интерпретации (видимость, ширина/порядок, шкалы) сохраняются по скважине в отдельном namespace, включая просмотр locked. Изменение настроек не меняет геологический результат/ревизию/историю. При отказе storage настройки действуют в сеансе с сообщением; reset касается только настроек. Разломы приняты пользователем как ручные линии без смещения пластов.

### Завершение автономных разрезов — 13.10.2026

- Независимый сегмент: карта → две точки кликами/координатами → начало/конец и ориентация → preview длины соединителя/влияния → Apply одной командой или Cancel/Escape. Недопустимая геометрия блокируется; незавершённый инструмент защищает переход.
- Треки: общая настройка состава/порядка/ширины → при необходимости override скважины → Save/reload → тот же состав в чертеже. «Использовать общие» снимает override; внешние источники не подключаются.
- Замкнутая дуга: кольцо → две вершины → короткая/длинная → операция → preview → Apply/Cancel → Undo/Redo. Контакты фиксированы; противоположный путь не изменяется. Пока preview открыт, конфликтующие редакторы неактивны.
- Изменение исходных данных: preview последствий перечисляет сброшенные несовместимые операции дуг → Apply изменяет входы и зависимую геометрию вместе → один Undo восстанавливает оба состояния.
- Старое локальное сохранение с пачками: открыть → нормализация только в памяти, сохранение фундамента → явный Save очищает старые поля. Ошибка цикла ссылок не перезаписывает хранилище. Старый `mode=rhythm` открывает пропластки без старого выбора.

Проверенные сценарии, ограничения и связь с РП/видео — в [итоге реализации](../../geo-module-refs/geology-implementation-report.md).

### Рабочая область геологии — 13.10.2026

Главное меню «Геология» → второй ряд «Разрезы / Интерпретация» → контекст выбранного документа восстанавливается. Dirty/preview защищают этот переход прежним диалогом; «Остаться» сохраняет ввод, Save-and-continue требует успешной записи. Разделы выбранного разреза переключаются верхним WorkspaceTabs с Arrow/Home/End.

Реестр → быстрый поиск → кнопка фильтров → тип/год/залежь/группировка → список и число результатов меняются сразу, URL сохраняет сочетание параметров. Пустой результат имеет сброс; Escape закрывает панель и возвращает фокус. Выбранный документ не подменяется фильтром.

График → колёсико меняет экранный масштаб около указателя; Shift/горизонтальное колесо прокручивает. Геометрия и физический масштаб печати не меняются. Hover → краткая подсказка; ПКМ/Shift+F10 → контекстное меню → сведения → закрыть/возврат фокуса. Enter на фокусируемом объекте открывает сведения напрямую. Доступ к карточке есть у viewer; команда выбора появляется только для допустимой опоры/ручного объекта текущего редактора. ПКМ на скважине карты не добавляет её в состав.

[Спецификация, техническое устройство и проверка](../task/geology-workspace-refresh.md).

### Перемещение по научному графику — 13.10.2026

Приблизить колесом/кнопкой → зажать ЛКМ на графике → переместить видимую область → отпустить. Движение менее 5 px остаётся кликом; после drag выбор/добавление объекта не срабатывает. Escape или pointercancel возвращает камеру к началу жеста. Ввод/исходные координаты и Undo/Save не меняются от навигации. При полном вписывании разреза камера ограничена его диапазоном; пустые области за пределами не открываются.

Рабочий разрез: zoom меняет диапазон X/Z в рамке, подписи/числа/точки/линии сохраняют экранный размер. Колесо привязано к указателю; Shift-wheel и горизонтальный жест перемещают по X, стрелки — по X/Z. «Вписать» сбрасывает pan/zoom/вертикальное увеличение. Редактируемый узел захватывает свой жест раньше камеры; активное построение точек сохраняет назначение ЛКМ. Контекстное меню/карточка сведений продолжают работать. Карта перемещается ЛКМ в режиме «Выбор», в том числе у viewer; остальные инструменты сохраняют прежние действия.


### Автономная интерпретация: уточнение локального этапа 2

Параметры метода вводятся в отдельный черновик → Apply параметров либо Calculate/Preview → Apply результата → Save документа. Уход с незавершённым вводом защищён; отмена параметров возвращает сохранённый в документе набор. Изменение входов сразу инвалидирует зависимые результаты, даже до применения пересчёта источника. Split/merge/contact — одна отменяемая команда с пересчётом метрик. Применение фактического фильтра ТК согласует внешние секции РМ, но не пересчитывает расход молча. Переключение вида/шкалы/соседа не меняет расчёт и его статус. Паспорт: выбрать лист/диапазон/масштаб → применить оформление → SVG/JPEG/печать; слишком большой диапазон блокируется. Ни одна операция не пишет в БГД или разрезы.


### Альфа: предложение фильтра и версия расчёта

Актуальные ЭК/ТК → настройки ГК → preview/Apply → поиск фиксированной длины предложения → ручной drag предложения → сравнение с фактическим ТК и ЗАДР → CSV/паспорт. Предложение не изменяет факт ТК. Смена морфологии меняет параметры; пересчёт границ запускается отдельным флажком. Новая версия алгоритма отмечает прежние результаты устаревшими, исходные данные и результаты сохраняются до явного пересчёта/Apply.
