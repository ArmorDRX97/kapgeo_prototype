# База геологических данных

Текущий геологический продукт ограничен БГД. Он ведёт месторождения, участки, залежи, кондиционные лимиты и единую карточку скважины.

## Карточка месторождения

Разделы: основные сведения, участки и залежи, кондиционные лимиты, скважины, редактирование. Код неизменяем после создания; RU/KZ/EN-названия обязательны; destructive actions учитывают зависимости.

## Карточка скважины

Разделы: описание, проходка, освоение, геология, каротажи, керновые рейсы, керновые пробы, литология и рудные интервалы. Данные проходят предметную валидацию, сохраняются версионно и восстанавливаются после reload.

Обзор геологии, карта, общий реестр скважин, интерпретации, разрезы, запасы, моделирование и публикация отсутствуют в `main`.
