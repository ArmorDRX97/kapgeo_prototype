# База геологических данных

Текущий геологический продукт ограничен БГД. Он ведёт месторождения, участки, залежи, кондиционные лимиты и единую карточку скважины. Постоянная панель второго уровня держит текущее месторождение и список скважин доступными на всех маршрутах БГД.

## Контекстная панель

Верхняя карточка объединяет переключатель месторождения и переходы к основным сведениям, участкам/залежам и кондиционным лимитам. Ниже расположен прокручиваемый список скважин с поиском, избранным, фильтром «Требуют внимания» и быстрым созданием при наличии разрешения. Создание месторождения выполняется только в административном модуле. Отдельной витрины месторождений нет: вход через пункт «Геология» сразу открывает основные сведения текущего объекта, а его смена выполняется только в этой панели.

## Карточка месторождения

Разделы: основные сведения, участки и залежи, кондиционные лимиты, скважины, редактирование. Код неизменяем после создания; RU/KZ/EN-названия обязательны; destructive actions учитывают зависимости.

## Карточка скважины

Разделы: описание, проходка, освоение, геология, каротажи, керновые рейсы, керновые пробы, литология и рудные интервалы. Данные проходят предметную валидацию, сохраняются версионно и восстанавливаются после reload.

Обзор геологии, карта, общий реестр скважин, интерпретации, разрезы, запасы, моделирование и публикация отсутствуют в `main`.
