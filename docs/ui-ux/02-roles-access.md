# Роли и доступ БГД

## Активная персона

Прототип использует одну фиксированную synthetic-персону:

- `R1 Геолог` — Ирина Иванова;
- область: `Сарытау · Северный`;
- после входа всегда открывается `/geology/bgd`;
- смена роли недоступна.

## Разрешения

R1 может просматривать, создавать, редактировать и удалять разрешённые месторождения, создавать участки и версии кондиционных лимитов, а также создавать и изменять все разделы скважины БГД.

Удаление месторождения блокируется зависимостями. Утверждённые наборы кондиций изменяются через новую версию. Проверки выполняются через permission + object scope, а не через текстовое имя роли в компоненте.

Промышленная авторизация, серверная ACL, ЭЦП и управление пользователями не входят в прототип.
