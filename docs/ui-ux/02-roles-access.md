# Роли и доступ

## Демонстрационные персоны

Восстановлены все 14 synthetic-персон прежней полной версии: R1 Геолог, R2 Геофизик-интерпретатор, R3 Инженер по запасам, R4 Геотехнолог-моделист, R5 Гидрогеохимик, R6 Технолог добычи, R7 Диспетчер, R8 Лаборант, R9 Механик, R10 Мастер РВР, R11 Аналитик, R12 Главный технолог, R13 Администратор системы и R14 Администратор AI-моделей. Персону можно сменить в `/profile`; верхнее меню и домашний маршрут обновляются сразу.

## Разрешения

Доступ к БГД, Геологии, Технологии, Моделированию, Аналитике и Администрированию определяется отдельными module permissions. `bgd.view` защищает рабочий контур БГД, а `geology.view` открывает самостоятельную интерпретацию. R1 ведёт БГД, но не создаёт корневое месторождение. Разрешение `geology.bgd.create` назначено только R13 и реализовано в административном модуле. R14 видит администрирование, но не имеет этого разрешения. Остальные права на разделы скважин сохранены из полной ролевой модели.

Удаление месторождения блокируется зависимостями. Утверждённые наборы кондиций изменяются через новую версию. Проверки выполняются через permission + object scope, а не через текстовое имя роли в компоненте.

Для инклинометрии R1 вводит, редактирует, рассчитывает, удаляет промеры и назначает основной; R2 дополнительно открывает demo-import; R13 имеет полный доступ. Остальные пользователи с доступом к БГД видят промеры только для чтения.

Прямой URL защищён теми же module permissions и показывает forbidden-состояние. Промышленная авторизация, серверная ACL, ЭЦП и изменение реальных пользователей не входят в прототип.

Справочники защищены отдельными `administration.references.view/create/update/status/delete`. R13 имеет все пять разрешений; R14 — только просмотр. Редактирование БГД не даёт права управления справочниками. Финальная матрица с «Администратором данных» требует согласования (OQ-ADM-01).

Интерпретация требует `geology.view` для просмотра и отдельного `geology.interpretation.edit` для изменений. Demo-edit назначен R1/R2/R13. В компоненте дополнительно проверяются scope `interpretation-demo` и status `draft`; DEMO-102 зафиксирована для всех. Права на БГД не подменяют разрешение интерпретации. Это временная матрица прототипа, промышленная остаётся OQ-INT-04.
