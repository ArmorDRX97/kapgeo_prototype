# Приёмка KAPGEO БГД

## Основной сценарий

1. Открыть `/auth/sign-in` и войти без обязательных demo-credentials.
2. Убедиться, что открыта `/geology/bgd`, а в меню нет переключателя и других модулей.
3. Открыть `Сарытау`, пройти все вкладки карточки месторождения.
4. Открыть `WELL-1010-FULL` и проверить девять вкладок скважины.
5. Изменить допустимое поле, сохранить, перезагрузить и подтвердить новую версию.
6. Проверить desktop 1280+ и mobile 390 px без page overflow и console errors.

## Технические критерии

- старые routes не входят в route tree;
- код экскурсии и переключателя отсутствует;
- typecheck, tests, lint и production build проходят;
- synthetic data восстанавливаются общим reset.
