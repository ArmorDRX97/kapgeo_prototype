# Реестр экранов KAPGEO БГД

| ID | Экран | Route |
|---|---|---|
| AUTH-01 | Вход | `/auth/sign-in` |
| GEO-00 | Рабочее место интерпретации, вход с выбранной demo-скважиной | `/geology` |
| GEO-INT-01 | Литология: источник по керну, редактирование по каротажу/сводной, кривые, свойства, реестр | `/geology?well=...&mode=lithology` |
| GEO-INT-02 | Технологические интервалы: ручная разметка, параметры КС, предпросмотр и применение | `/geology?well=...&mode=technology` |
| GEO-INT-03 | Привязка керна: исходная/сводная литология, сегменты, промер, составные пробы | `/geology?well=...&mode=core` |
| GEO-INT-04 | Свойства сегмента: split/merge, мощность/контакт, вставка/удаление/восстановление, операции рейса | правая панель GEO-INT-03 |
| GEO-INT-05 | Часть сводной пробы КП/ГС/ЛГХ/ТП: создание/изменение/расширение/удаление | правая панель GEO-INT-03, `selection=sample:...` |
| GEO-INT-06 | Групповое удаление полностью попавших интервалов | правая панель GEO-INT-01/02 |
| GEO-BGD-01 | Вход в БГД: автоматическое открытие основных сведений текущего месторождения или empty state | `/geology/bgd` |
| GEO-BGD-02 | Карточка текущего месторождения: сведения, участки и залежи, кондиционные лимиты, скважины, редактирование | `/geology/bgd/:depositId?section=...` |
| GEO-BGD-03 | Создание/редактирование скважины | `/geology/bgd/:depositId/wells/new`, `/geology/bgd/:depositId/wells/:wellId?tab=...` |
| TECH-00 | Входная заглушка технологии | `/technology` |
| MOD-00 | Входная заглушка моделирования | `/modeling` |
| AN-00 | Входная заглушка аналитики | `/analytics` |
| ADM-01 | Администрирование: сводка ролей и создание месторождения | `/admin` |
| ADM-02 | Три таба, перечень справочников строками-карточками и постоянная правая панель полей/истории | `/admin/references?dictionary=...&entry=...` |
| ADM-03 | Добавление/изменение значений в правой панели; подтверждение статуса/удаления в диалоге | панель/диалоги ADM-02 |
| PROF-01 | Профиль и переключение synthetic-роли | `/profile` |
| SYS-403 | Недостаточно прав для модуля | route guard |
| SYS-404 | Страница не найдена | fallback |
| SYS-ERR | Ошибка приложения и сброс данных | global boundary |

Вкладки `GEO-BGD-03`: описание, проходка, освоение, геология, инклинометрия, каротажи, керновые рейсы, керновые пробы, литология и рудные интервалы.

GEO-INT-01…03 — три режима одного рабочего места: контекст слева, Canvas-планшет в центре, постоянные свойства справа и сворачиваемый реестр снизу. Независимы от объектов БГД. `from/to` сохраняют окно глубины, `selection` — выбранный объект; loading, отсутствие данных, ошибка хранилища, неизвестная скважина, forbidden и read-only предусмотрены.

GEO-INT-04…06 — состояния существующей панели без новых маршрутов. Расчёт имеет potential/gradient и stale preview; DEMO-104 показывает stale соответствие с явным восстановлением, очисткой history и отдельным Save. Таблицы показывают средний КС, связанные части выбранного материала и пересчитанные рейсы.

Удалены из `main`: прежние полнофункциональные рабочие области технологии, моделирования, аналитики и администрирования, домашний экран, задачи, методический центр, справочный центр и экскурсия. Их новые module routes не заявляют несуществующую функциональность.
