# Реестр экранов KAPGEO БГД

| ID | Экран | Route |
|---|---|---|
| AUTH-01 | Вход | `/auth/sign-in` |
| GEO-BGD-01 | Витрина месторождений | `/geology/bgd` |
| GEO-BGD-02 | Карточка месторождения: сведения, участки и залежи, кондиционные лимиты, скважины, редактирование | `/geology/bgd/:depositId?section=...` |
| GEO-BGD-03 | Создание/редактирование скважины | `/geology/bgd/:depositId/wells/new`, `/geology/bgd/:depositId/wells/:wellId?tab=...` |
| PROF-01 | Профиль геолога | `/profile` |
| SYS-404 | Страница не найдена | fallback |
| SYS-ERR | Ошибка приложения и сброс данных | global boundary |

Вкладки `GEO-BGD-03`: описание, проходка, освоение, геология, каротажи, керновые рейсы, керновые пробы, литология и рудные интервалы.

Удалены из `main`: домашний экран, задачи, общий геологический модуль и методический центр, технология, моделирование, аналитика, администрирование, уведомления, справочный центр и экскурсия.
