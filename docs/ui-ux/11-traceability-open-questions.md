# Трассировка и открытые вопросы БГД

## Зафиксированные решения

- `main` содержит рабочую БГД и расширяемый shell; полный прежний прототип хранится в `archive/full-prototype-2026-09-15`;
- переключатель `Минимум` удалён;
- восстановлены 14 synthetic-персон, доступ к модулям рассчитывается по permission;
- создание месторождения перенесено в `/admin` и доступно R13;
- экскурсия удалена из `main`, но сохранена в архивной ветке для будущей адаптации под БГД;
- production backend и реальные данные не входят в текущий DoD.

## Открытые вопросы

- OQ-BGD-01: промышленная схема ACL и объектных областей;
- OQ-BGD-02: backend contract и миграция IndexedDB prototype data;
- OQ-BGD-03: утверждённые формулы рудных интервалов и метропроцента;
- OQ-BGD-04: новый сценарий обучения, спроектированный только для БГД;
- OQ-BGD-05: окончательный состав RU/KZ/EN-справочников.
- OQ-ADM-01: итоговые разрешения «Администратора данных» из UC.KAPGEO.ADM.04; пока R13 управляет справочниками, R14 только читает, новая роль не вводится.
- OQ-ADM-02: форматы импорта/экспорта, обновление существующих кодов, частичные ошибки и правила слияния; текущий JSON-экспорт только synthetic, промышленный импорт не реализован.
- OQ-ADM-03: точные схемы `device_type` и `reff_well_development_method` отсутствуют в выгрузке; временные общие поля помечены в UI. `reff_colour` не содержит RGB/HEX — не добавляем неподтверждённое поле.
- OQ-ADM-04: обязательность/nullability полей reff; интеграция справочников с другими модулями исключена из текущей задачи по явному уточнению пользователя.

На 1 октября 2026 управление справочниками реализовано по переданным HTML источникам; схемы сохранены в `src/entities/reference-data/model/catalog.ts`, поведение описано в `modules/03-reference-data.md`. Архивные материалы для этого решения не использовались.
