- OQ-INT-06: крайние случаи удаления/overwrite, полный набор свойств для auto-merge и разрешённый диапазон сводной колонки после каскадного сдвига.

### Решения расширения, 05.10.2026

- Минерализации — канонический набор без учёта порядка; auto-merge литологии сравнивает породу/набор/цвет/примечание. Цвет керна отсутствует в литологии по каротажу. Группа удаляет только полностью попавшие строки. Технологическое удаление заполняется верхним соседом; без него остаётся gap.
- Потенциал/градиент и средний КС реализованы как demo по записанным правилам экстремумов/порогов/округления/gap. OQ-INT-02 остаётся промышленным согласованием, наличие кнопок и вычислений его не закрывает.
- Ограничение промера из РП применено: исходная мощность среза, 0,1 или 0; без промера — изменение. Привязка линейная/отражённая, связанная модель атомарная, исходные срезы не теряются. Общая контактная точка измерения принадлежит нижнему срезу. OQ-INT-03 остаётся вопросом применимости в новой промышленной системе.
- Каскадные изменения допустимы в 0…глубина скважины; пересечение сводных сегментов запрещено. Merge пока только внутри одного исходного core-id. Оригиналы с нулевой мощностью восстанавливаются, вставленные бескерновые удаляются полностью.
- Core-команды пересоздают сводную литологию всей области керна, включая её ручные правки, с предупреждением и undo. Явный reset по буровой колонке сбрасывает сводные правки/пробы и очищает undo; версия источника делает старое соответствие read-only до reset. Реальный источник БГД остаётся OQ-INT-05.
- Существующий localStorage namespace сохранён; старые mappings дополняются явными gap-сегментами, не заменяются fixture. Настройки колонок остаются временными. Утверждение/печать, реальная ACL, лаборатория и методы — следующие отдельные этапы.
