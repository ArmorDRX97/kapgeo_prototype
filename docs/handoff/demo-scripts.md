# Demo scripts

## 30 минут — для заказчика

1. Войти как технолог и показать ролевую навигацию.
2. Открыть WELL-1010, её данные, интерпретацию и геологическую публикацию.
3. Перейти в TECH: замеры → баланс → РВР → отчёт.
4. Открыть ANALYTICS: причина → evidence → решение → задача.

## 60 минут — для продуктовой команды

Добавить modelling snapshot/run/results, admin permissions и workflow-центр.

## 90 минут — для implementation-команд

Пройти роли, URL-state, версии, demo data, компонентные состояния, backlog production gaps и API assumptions.
