Эта папка — стартовая точка передачи интерактивного demo-прототипа командам design, frontend, backend и QA.

- `demo-scripts.md` — сценарии демонстрации на 30/60/90 минут;
- `api-integration-assumptions.md` — контракты и то, что остаётся за пределами прототипа;
- `production-gaps.md` — честный backlog production-слоя.
- `traceability-e00-e16.md` — доказательная матрица эпиков и gate финального закрытия.
- `i18n-accessibility-strategy.md` — честный demo scope и production-план E14.
