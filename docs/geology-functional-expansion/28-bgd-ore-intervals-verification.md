# Проверка рудных интервалов БГД

Дата: 15.09.2026  
Постановка: `UC.KAPGEO.BGD.10 Ведение рудных интервалов и ОРИ` из предоставленного пользователем HTML и трёх legacy-скриншотов.

## Реализованный кликабельный срез

- URL-вкладка карточки сохранённой скважины: `?tab=ore-intervals`.
- Обязательные поля `Источник выделения` и `Элемент` в контексте, формах и табличном представлении.
- Прямой режим: создание, изменение и удаление рудного интервала; расчёт мощности; ввод по содержанию либо метропроценту; проверка глубины и пересечений в одном источнике/элементе.
- Каждый новый рудный интервал автоматически получает одиночное ОРИ.
- ОРИ: calculated-таблица, выбор последовательных объединений, merge, split, отсоединение верхней/нижней части через выбранного ребёнка.
- Дифференциальный режим: CRUD свободных интервалов, текстовая и цветовая индикация принадлежности, создание рудного интервала из непрерывной последовательности, правило проницаемости по преобладающей мощности с выбором `Непроницаемый` при равенстве.
- Локальное сохранение versioned workspace, дочерних records, relations и audit event в IndexedDB.
- Права: полное управление R1/R13; R2 изменяет гамма-каротаж и КНД, но видит керн/паспорт только для чтения.

## Осознанные границы

Это прототип без backend, production API, реальных/тестовых производственных данных и файлового импорта. Исходное состояние детерминированно synthetic. Формула `метропроцент = содержание × мощность`, обратный расчёт и взвешенная агрегация ОРИ нужны только для кликабельной демонстрации и помечены `Demo`; production-формулы, округление, допустимые диапазоны, проверка границ технологических интервалов и зависимость от запасов зафиксированы в `OQ-33`.

## Автоматические проверки

- typed URL `?tab=ore-intervals`;
- обязательность provenance-полей и открытие дифференциальной вкладки;
- расчёт complementary demo value и overlap validation;
- merge последовательных ОРИ и пересчёт summary;
- continuity/free-membership дифференциальных интервалов;
- сохранение новой версии, relations и audit evidence.

Итог: `typecheck`; 56 test files / 134 tests; `lint` без ошибок (3 прежних warnings вне среза); production `build`. Browser smoke на `WELL-1042` подтвердил создание рудного интервала из двух соседних дифференциальных интервалов, появление четвёртого ОРИ, сохранение `v2` после reload и отсутствие ошибок консоли.

После визуальной проверки таблица дифференциальных интервалов получила отдельную сетку с увеличенными колонками типа и связи и компактным заголовком `Сод., %`: на рабочей ширине таблицы `clientWidth = scrollWidth = 993 px`, наложения и внутреннего overflow нет.
