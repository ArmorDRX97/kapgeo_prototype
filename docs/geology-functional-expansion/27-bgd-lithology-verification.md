# БГД — ведение литологии

Дата: 15 сентября 2026  
Статус: реализовано в кликабельном прототипе.

## Граница

В карточку сохранённой скважины БГД добавлена URL-вкладка `?tab=lithology`. Это browser-only демо-сценарий: нет бэкенда, реального импорта, автоматической интерпретации или production-хранилища.

## Кликабельный результат

- переключаются раздельные версионные колонки `По керну / По каротажу / Сводная`;
- колонка, таблица и редактор работают с одним выбранным интервалом;
- показаны границы, рассчитанная мощность, порода, минерализация, цвет, стратиграфия, описание и источник;
- доступны add, split, merge, copy from above, delete, undo/redo, diff и interval validation;
- ошибки границ, overlap и выход за глубину блокируют сохранение; gap остаётся видимым предупреждением;
- сохранение создаёт новую версию только изменённого track и audit event в существующем IndexedDB `kapgeo-demo`;
- профили без полного update-разрешения видят read-only состояние;
- пустая новая скважина показывает честный empty state, а прежние локальные записи дополняются совместимо без обязательного reset.
