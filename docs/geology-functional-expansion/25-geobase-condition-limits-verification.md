# БГД: кондиционные лимиты в карточке месторождения

Дата актуализации: 28 августа 2026  
Статус: реализованный вертикальный срез кликабельного прототипа

## Назначение

Карточка месторождения `/geology/bgd/:depositId` даёт геологу компактный доступ к действующим кондиционным лимитам участков без перехода в отдельную desktop-форму старой системы.

## Реализованное поведение

- раздел «Кондиционные лимиты» расположен рядом со связанными участками и залежами;
- по каждому участку показаны код набора, дата действия, версия, состояние, плотность и бортовое содержание;
- «Полный список» открывает модальное окно с прокручиваемой двухколоночной таблицей «Параметр / Значение»;
- набор включает параметры разреза и фильтров, бортовое содержание, мощность пересечений, каротажные ограничения, минимальные запасы, поправки азимута, плотность и прочие значения из переданного перечня;
- данные принадлежат существующей versioned-сущности `ConditionSet`, не дублируются в карточке и сохраняются в IndexedDB;
- ранее сохранённые наборы без перечня лимитов автоматически получают совместимый полный набор при чтении;
- опубликованная версия отображается read-only; редактирование и выпуск новой версии остаются в рабочей области кондиций.

## Проверка

1. Открыть `/geology/bgd/DEP-SARYTAU` под ролью Геолог.
2. В разделе «Кондиционные лимиты» убедиться, что отображается набор участка «Северный».
3. Нажать «Полный список» и проверить заголовок, версию и прокручиваемые строки таблицы.
4. Закрыть окно кнопкой или кликом по затемнению вне окна.
5. Проверить сохранённый ранее браузерный профиль: список доступен и после reload.
