# UC.KAPGEO.BGD.08 — керновые данные в карточке скважины

Дата: 9 сентября 2026
Статус: реализовано в кликабельном synthetic-прототипе.

## Реализованный срез

- `?tab=core-runs` объединяет реестр и форму создания/редактирования кернового рейса в responsive master-detail экране.
- Длина рейса и процент выхода рассчитываются автоматически; проверяются номер, границы, глубина скважины, пересечение рейсов и выход керна.
- «Промер керна» расположен внутри выбранного рейса. Запись содержит дату, оператора, описание, колонку `DRILLING/COMPOSITE` и несколько интервалов с мощностью дозы в мкР/ч. Пустое значение сохраняется как отсутствие замера, ноль — как измеренный результат.
- `?tab=core-samples` объединяет реестр и редактор проб. Проба содержит несколько интервалов с обязательной привязкой к рейсу, глубины по бурению и опциональную пару скорректированных глубин.
- Лабораторные результаты содержат показатель, единицу, число либо отсутствие замера и qualifier `<`/`>`.
- Удаление рейса блокируется при связанных интервалах промера или проб с перечислением количества зависимостей. Удаление пробы после подтверждения удаляет её интервалы и результаты.
- Общий workspace versioned, хранится в IndexedDB и добавляет audit event для каждой операции. Seed-данные явно маркированы `synthetic`.
- R1/R13 управляют рейсами и пробами; R1/R2/R13 управляют радиометрическим промером; остальные профили видят read-only состояние.

## Граница прототипа

Excel-импорт, справочники заказчика, отдельная роль лаборанта и зависимости от литологии по керну остаются за пределами этого вертикального среза. Они не имитируются как готовые действия.

## Проверки

Покрыты unit-тестами overlapping/impossible recovery, уникальность номера пробы с учётом вида, интервал в границах рейса, сохранение нулевого результата, persistence, optimistic version conflict и audit evidence.

Browser QA в Chrome подтвердил прямые URL в режиме `Минимум`, master-detail компоновку, создание промера только внутри выбранного рейса, сохранение после reload, создание пробы с рейсовым интервалом, формат глубин и различие `0`/`Нет замера`.
