# Интерпретация: требования из РП

Источник: корневой `РП по геологическому модулю.pdf`, пп. 1.24–1.26, с. 80–107. Исследование 05.10.2026. Это описание legacy-поведения; адаптация UX и ограничения прототипа отдельно указаны в плане.

## Проверка границ задачи

Да: 1.24 «Разметка и интерпретация литологии», с. 80–87; 1.25 «Интерпретация технологических интервалов», с. 87–92; 1.26 «Интерпретация керна», с. 92–107. Все три находятся внутри программы «Скважина». Интерпретация литологии в 1.24 ручная; автоматическое разбиение по КС предусмотрено в 1.25. Автоматического AI-определения пород здесь нет.

## 1.24. Литология

- Три режима данных: по керну, по каротажу, сводная литология. Не три независимых приложения.
- Единый чертёж с общей глубиной: контакты, цвет керна, литология, минерализации, несколько каротажных кривых; можно добавлять другие литологические колонки, рейсы и технологические интервалы (рис. 1.43).
- Новая разность: указать две глубины на чертеже, уточнить их численно, задать породу, набор минерализаций, цвет; применить или отменить (рис. 1.44).
- Изменить границу: выбрать существующий контакт и новое положение; свойства доступны отдельно.
- Вставка/расширение удаляет или усекает перекрытые интервалы; соседние с одинаковым полным набором параметров автоматически сливаются.
- Удалить один интервал или группу: для группы удаляются только полностью попавшие в выбранный диапазон интервалы.
- Команды доступны через панель режимов и контекстное меню; undo/redo (рис. 1.43).
- Настройки: глубинный масштаб, увеличение/просмотр, шаг округления глубины (например 0,1 м), видимые колонки, ширина/положение/порядок, восстановление по умолчанию (рис. 1.45–1.46).
- Настройки графиков: произвольное число кривых, в том числе одного типа, разные масштабы, начало шкалы, ограничение по глубине; авто/ручной масштаб (рис. 1.47).
- Проверка литологии по керну: цвет каждой разности, сумма мощностей в рейсе равна выходу керна, разности лежат в пределах рейсов (с. 87).

## 1.25. Технологические интервалы

- Общая глубина, контакты, бинарная колонка технологических/нетехнологических интервалов, каротажи (рис. 1.48). Это не рудные интервалы и не ОРИ.
- Ручной режим: новый интервал переключает тип относительно типа в первой выбранной точке; перемещение контакта; удаление одного/группы; undo/redo.
- Перекрытые интервалы усекаются/удаляются; соседние одного типа объединяются. Удалённую область занимает непосредственно прилегающий сверху интервал (с. 89); случай отсутствия верхнего соседа отдельно не определён.
- Автоматический режим: отдельное окно «Разбиение / Интерпретация КС», глубины от/до, метод, порог КС, округление, минимальные мощности по двум типам, направление сверху/снизу; для градиент-зонда — продолжить последний проницаемый (рис. 1.49, с. 89–92).
- «Рассчитать» формирует редактируемую таблицу результата. Изменение параметров требует повторного расчёта. «ОК» переносит результат с предварительным удалением всех прежних интервалов редактора; «Отмена» ничего не меняет. В новом UX нужна явная проверка последствий замены.
- Потенциал-зонд: контакты в точках пересечения КС с порогом, округление глубин; ниже порога — непроницаемый, выше — проницаемый. Слишком тонкий прослой присоединяется к предшествующему по направлению расчёта.
- Градиент-зонд: начальный тип задаётся порогом; переходы по локальному минимуму ниже порога и локальному максимуму выше порога. Тонкие прослои присоединяются к предыдущему по ходу; последний до границы диапазона. При «продолжить проницаемый» искать за диапазоном следующий соответствующий минимум.
- Не определены: равенство порогу в потенциал-методе, интерполяция между точками, плато/шум/пропуски, крайние тонкие интервалы, порядок округления/фильтрации. Для прототипа допустим явно маркированный детерминированный demo-расчёт; промышленную методику не объявлять подтверждённой.
- Настройки колонок и графиков переиспользуются из 1.24.

## 1.26. Керновый интерпретатор

### Запуск и исходные данные (с. 92–95)

- Вход: рейсы, выход керна, литология поднятого керна, промер, пробы. Логические связи legacy устанавливает по глубинам.
- Хранится соответствие глубин «по бурению ↔ сводная колонка». Если его нет — стартовое соответствие тождественное, колонка копируется по бурению.
- Проверять выход/мощность керна, сумму литологии, пересечение промера или пробы с бескерновым интервалом. При ошибках работа требует исправления исходных данных.
- Если исходные данные изменены и соответствие устарело — сообщение и предложение удалить соответствие и перезапустить. Не молчаливый сброс.
- Сводные свойства подгружаются только при согласованности со сформированными интервалами.
- Разделение по рейсам, наличию керна и наличию/отсутствию промера. Бескерновые интервалы возможны и вне рейсов.

### Связанные данные и команды (с. 94–103)

- Для кернового интервала сохранять исходный и сводный диапазоны, связанные литологические разности, промер, пробы. При перемещении/перевороте/изменении мощности переносить связанные данные согласованно.
- Для бескернового интервала — одна предполагаемая разность и минерализации, без цвета керна; у вставленного интервала исходного диапазона может не быть.
- Рейсы: перестановка, переворот; операции автоматически применяются к составляющим интервалам.
- Интервалы: перестановка, переворот, изменение мощности с фиксацией кровли или подошвы и сдвигом прочих, изменение контакта только двух соседей, разрезание, объединение, вставка бескернового, удаление/восстановление.
- После операций пересчитывать положения, длины и выходы рейсов.
- При нулевой мощности сохранять исходный керновый/исходный бескерновый интервал как скрытый восстанавливаемый объект. Полностью удалить можно добавленный бескерновый без исходной мощности. Legacy показывает красный треугольник, в новом UI нужны также подпись/счётчик.
- Split: бескерновый наследует свойства; керновый делит связанные разности, промер и пробы между частями.
- Merge: только соседние одного типа в одном рейсе, прилегающие также по буровой колонке. Нельзя объединять керновый с промером и без промера. Бескерновый сохраняет свойства выбранного; керновый восстанавливает данные из буровой колонки.
- Ограничение legacy для мощности кернового интервала с промером: исходная мощность, 0,1 м (шаг промера) или 0. Применимость к новой программе требует подтверждения (с. 102–103).
- Свойства сводного керна можно вернуть к исходным; описание бескернового сбросить. Изменённые свойства, переворот, сжатие/растяжение и удаление должны различаться визуально и текстом.
- Сброс интерпретации к буровой колонке требует подтверждения и исключён из undo (с. 103, 107).

### Литология по каротажу и пробы (с. 103–107)

- Редактирование литологии по каротажу: контакт, split, merge, свойства, визуальное перемещение.
- Среднее КС разности автоматически рассчитывается при запуске и изменении границ. Нужны реальные для demo точки КС и явно заданный способ усреднения.
- Сопоставление исходных и сводных интервалов четырёх видов: керновые (КП), грансостав (ГС), литогеохимические (ЛГХ), технологические (ТП).
- Создание сводного интервала пробы: номер, от/до или мощность; автоматический обратный расчёт глубин поднятого керна. Нельзя выйти за соответствующий керновый интервал и рейс.
- Расширение до верхнего/нижнего соседнего интервала. При вставке пересекающиеся пробы усекаются, делятся или удаляются; область применения по виду пробы нужно явно определить.
- Редактирование номера/границ; удаление через нулевую мощность в legacy. Две точки на чертеже открывают заполненную форму.
- Все диалоговые и визуальные операции, кроме сброса, поддерживают undo/redo.
