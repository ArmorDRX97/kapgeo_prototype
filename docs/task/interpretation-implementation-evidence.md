# Интерпретация: реализация и проверка первого прототипа

Исторический evidence первого среза. Актуальное покрытие и ограничения после расширения РП: [второй срез](./interpretation-second-slice.md). Ниже сохранены прежние проверки и исходные ограничения.

Дата: 05.10.2026. Актуальный итог задачи. Основная продуктовая спецификация: [геологический модуль](../ui-ux/modules/02-geology.md); источники: [РП](./interpretation-requirements.md), [скриншоты](./interpretation-screenshot-review.md), [анализ стека](./interpretation-frontend-dependencies.md).

## Принятый объём

Пользователь попросил реализовать здесь кликабельный прототип на графическом пакете основного frontend. Входные данные придумать и держать отдельно от БГД. Поэтому ранние предложения о входе из карточки БГД, общем context resolver, API-контракте и синхронном сохранении в БГД не входят в этот этап.

Рабочее место открывается по «Геология» или `/geology?well=int-demo-01&mode=lithology`. Это общий экран с тремя режимами, не последовательный wizard:

| Зона | Что реализовано |
|---|---|
| Слева | Учебное месторождение «Песчаный», поиск и 3 demo-скважины, сворачивание списка, сброс выбранного примера |
| Над планшетом | Скважина, synthetic-маркер, статус/сохранение, режимы, инструменты, undo/redo, колонки, масштаб, точное окно глубины |
| Центр | Canvas с численными КС/ГК и интервальными колонками на общей глубине; pan/zoom/crosshair, отдельные линейные/log-шкалы, горизонтальная прокрутка |
| Справа | Постоянная панель: свойства интервала, привязка керна, настройки кривой либо параметры расчёта; ошибки возле формы |
| Снизу | Сворачиваемый реестр интервалов; в керне — сегменты и части связанных проб, исходная и сводная глубины, неизменные лабораторные числа |

## Рабочие действия

**Литология (1.24, первый срез).** Вид: источник по керну / по каротажу / сводная. Источник неизменен. Выбор на Canvas или в реестре открывает точную форму. Создание drag от одной глубины до другой либо кнопкой «Ввести интервал» с числовыми полями. Свойства: порода, минерализация, примечание. Перекрытие обрезает/разбивает соседей, сохраняет вне диапазона; auto-merge только при совпадении всех свойств. Split по точной глубине, delete с подтверждением, drag контакта. Незавершённая форма — отдельный preview, её нельзя сохранить.

**Технологические интервалы (1.25, первый срез).** Ручное редактирование и расчёт по выбранной КС. В UI «Потенциал-зонд / Детерминированный demo-метод». Параметры: диапазон, порог, минимальная мощность. Используются полные точки, а не decimation; значение ≥ порогу — проницаемое. Пересечение линейно интерполируется, глубины округляются до 0,1 м. NaN-участки сохраняются как «Нет КС». Тонкие интервалы присоединяются к предыдущему известному, первый тонкий остаётся. Эти правила — demo-допущения до OQ-INT-02.

Предпросмотр визуально и предметно отдельный от текущих интервалов. Можно выбрать его строку и скорректировать форму. Изменение параметров делает результат устаревшим; применение требует пересчёта. Apply подтверждает замену **всех** текущих интервалов, переносит в черновик одним undo-шагом; Save отдельно. Cancel ничего не меняет. При переключении режима незавершённый расчёт остаётся явно обозначен.

**Керн (1.26, базовая демонстрация).** Выбрать сегмент, изменить начало внутри своего рейса и/или перевернуть порядок. Мощность фиксирована. Mapping переносит литологию, измерения и каждую часть пробы; анализы сохраняются. Сводная литология затронутого рейса пересоздаётся по керну, включая вручную изменённые интервалы: предупреждение находится в форме. Undo возвращает всю связанную модель вместе. Исходная колонка остаётся доступна для сравнения.

## Доступ и состояния

Просмотр: `geology.view`. Редактирование/расчёт/применение/сохранение: `geology.interpretation.edit` + scope `interpretation-demo` + status `draft`. Временная demo-матрица R1/R2/R13; в компонентах нет проверки имени роли. Locked-объект доступен только для просмотра даже этим персонам.

Loading, ошибочное/повреждённое сохранение с retry и локальным reset, неизвестная demo-скважина, forbidden, read-only, отсутствие кривых/керна и ошибки ввода предусмотрены. Смена скважины/уход с черновиком требует подтверждения отбрасывания; отмена оставляет пользователя на месте. Клавиатурный выбор через таблицу и точные формы, Ctrl+Z / Ctrl+Shift+Z; курсор/масштаб не засоряют историю. На узком экране свойства под планшетом, треки прокручиваются горизонтально.

## Проверка

Выполнены `npm run typecheck`, `npm run lint`, `npm run test` (35 файлов / 100 тестов) и `npm run build`. Сборка успешна; сохраняется предупреждение размера общего JS chunk (~838 kB), разделение bundle — отдельная задача.

Новые meaningful-проверки: NaN-gap/пик при decimation, overwrite/merge/contact/split, расчёт с разными порогами и gap, отсутствие входных данных, mapping/переворот составной пробы и неизменность анализов, атомарная history, независимость namespace, конфликт/повреждение storage, Canvas-композиция и реальные UI-команды, stale preview/apply/cancel, read-only по permission/status, двухточечный pointer-жест, deep link.

Браузер (локальный Vite, desktop и 390×844):

1. Литология: контакт 117,4 → 118,2 м, сосед обрезан согласованно; save и reload восстановили 118,2 м и статус «Сохранено».
2. КС: при пороге 25 — 14 интервалов, при 45 — 7. До пересчёта apply disabled; gap 128,3–129,2 м неизвестный. Применение изменило текущий результат, undo вернул 4 исходных интервала.
3. Керн: начало 113 м + переворот перенесли DEMO-КП-01 с 113–114,5 на 116,5–118 м; 0,024 сохранилось. Undo восстановил исходный диапазон и весь результат.
4. DEMO-102 read-only; DEMO-103 без КС запрещает расчёт и показывает пустой керн. При 390 px горизонтального переполнения страницы нет; колонки имеют свою прокрутку.
5. В конце проверки browser console errors/warnings: 0.

## Что оставлено на потом

### Исправление прокрутки, 05.10.2026

Клик по интервалу и wheel zoom обновляли `selection/from/to` в URL. TanStack Router по умолчанию сбрасывал scroll при каждой такой навигации: воспроизведено `scrollY: 450 → 0` после клика по Canvas. В `InterpretationPage` внутренние изменения URL теперь передают `resetScroll: false`; глобальное восстановление прокрутки других маршрутов не изменено. Проверено реальными click/wheel в браузере: положение `scrollY=575` сохраняется, выбранный интервал и окно глубины меняются. Две проверки уровня страницы покрывают Canvas-selection и wheel-navigation. [Скриншот проверки](./verification/interpretation-scroll-stable.jpg).
