## Источник и правила использования

- `РП по геологическому модулю.pdf` в корне проекта: «Руководство пользователя ГГИС», «Геологический модуль», версия 1.0, 2019; 339 страниц.
- SHA-256: `0d94d0a66c4e7651489f353a12f582f7ef5db3b8c4d2a5a9b7c7519d9f10c871`.
- В ссылках ниже используется номер страницы PDF; у проверенных разделов он совпадает с печатным номером.
- PDF описывает поведение старой программы. Актуальная продуктовая структура задаётся `docs/ui-ux/`; новые маршруты и правила ниже являются предложениями, пока явно не приняты.
- Архив не использовался. Исторические evidence-документы БГД могут содержать прежнее количество тестов и устаревшие номера OQ; актуальные вопросы — в `docs/ui-ux/11-traceability-open-questions.md`.
- Нельзя считать тип в TypeScript, fixture или заглушку доказательством законченного пользовательского процесса.

Первый и второй срезы готовы и проверены. Исторические планы фиксируют состояние до реализации; при расхождении приоритет имеют второй срез и `docs/ui-ux/`. Сохранять различие между требованиями РП, demo-допущениями и промышленной готовностью.
