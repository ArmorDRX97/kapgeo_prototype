# Интерпретация: расширение РП 1.24–1.26

05.10.2026. Актуальный второй срез после запроса «реализуем следующие возможности согласно РП 1.24–1.26». Продолжает первый автономный прототип; источник требований — ранее проверенная [выжимка РП](./interpretation-requirements.md). Повторное чтение PDF и архива для этой реализации не потребовалось. Вход `/geology`, тот же локальный `@kapgeo/geo-viz/wellog`, отдельные synthetic-данные; основной frontend и БГД не менялись.

## Реализованное покрытие

| РП | Новые действия и отображение |

| 1.25 | Потенциал- и градиент-зонд; выбранная КС, диапазон, порог, отдельные минимальные мощности проницаемых/непроницаемых, направление, округление, продолжение последнего проницаемого для градиента. Раздельный корректируемый preview/stale/recalculate/apply/cancel. Ручной новый тип противоположен типу в первой точке; удалённую область занимает верхний сосед, одинаковые соседние типы объединяются |

История обычных команд атомарная, до 40 действий. Save/reload сохраняет сегменты, свойства, пробы и параметры расчёта. Namespace прежний `kapgeo.interpretation.demo.v1:<wellId>`: старые сохранения дополняются явными бескерновыми областями, при этом сохраняются их положения, заметки и ревизии. Конфликт вкладок остаётся явной ошибкой. Сброс выбранного примера и восстановление буровой колонки требуют подтверждения и очищают историю.

## Как показать

1. DEMO-101 → Литология → выбрать разность → минерализации → Применить. Сводная литология дополнительно показывает цвет. «Удалить группу» принимает глубины; частично попавшие строки остаются. Любую обычную команду можно отменить.
2. Технологические интервалы → Рассчитать по КС → Градиент-зонд → направление/округление/минимумы → Рассчитать. Видна отдельная колонка и таблица. Изменение параметра блокирует применение до пересчёта. «Применить результат» заменяет все текущие интервалы после подтверждения.
3. Привязка керна → Керн 1 → Разделить на 114 м. КП-01 делится на 113–114 и 114–114,5 м; обе части имеют анализ 0,024. Часть 112–114 без промера можно растянуть; части с промером соблюдают ограничение РП.
4. Вид проб → ГС → Новая сводная проба → диапазон внутри одного кернового сегмента → Применить пробу → Сохранить. Переключение на КП/ЛГХ/ТП показывает их отдельные данные.
5. DEMO-104 → керн → все изменения соответствия блокируются → К буровой колонке / Восстановить соответствие → подтверждение → история пуста, редактирование доступно, Save отдельно.

## Точные demo-допущения и ограничения

- Потенциал: значение ≥ порогу считается проницаемым, пересечение линейное по полным точкам. Градиент: контакты на локальных минимумах ниже порога / максимумах не ниже порога; на плато выбирается последний экстремум. Начальный тип определяется значением в начальной точке и направлением. Пропуски/неположительные КС неизвестны, не соединяются через gap.
- Границы округляются выбранным шагом 0,1/0,2/0,5/1 м, затем применяется фильтр мощности по направлению. Тонкий слой сливается с предыдущим известным в направлении расчёта; первый тонкий сохраняется. Продолжение градиента ищет следующий подходящий минимум за диапазоном; останавливается на пропуске, при отсутствии минимума оставляет исходную границу.
- Средний КС — средневзвешенное по глубине интегрирование линейных отрезков первой RS-кривой; известная площадь / известная мощность. Отдельно показывается доля покрытия, NaN не заполняются.
- С промером разрешены исходная мощность **среза**, 0,1 м или 0; без промера разрешено растяжение/сжатие. Связи внутри среза преобразуются линейно, при перевороте отражаются. Общая контактная точка промера относится нижнему исходному срезу, крайняя нижняя точка оригинала сохраняется. Для сжатых частей внутренняя точность 6 знаков; таблицы для чтения округляют до 0,1 м.
- Оригинал с нулевой мощностью остаётся в таблице и восстанавливается со связями. Вставленный бескерновый без исходной глубины удаляется полностью; обычный undo возвращает его.
- Merge керна ограничен соседними срезами **одного исходного сегмента**, одного рейса, одинаковой ориентации и наличия промера. Объединение разных исходных core-id пока отсутствует. Исходные/вставленные бескерновые части с разным происхождением не сливаются.
- Числовая привязка остаётся внутри исходного рейса; каскадные операции допускают перенос всей сводной структуры в пределах 0…глубина скважины. Нельзя перекрывать сводные сегменты или терять/дублировать исходные срезы.
- Любая команда керна перестраивает сводную литологию всей области керна, включая её ручные правки; предупреждение есть в форме, undo возвращает их вместе. При reset по буровой колонке сводные правки и пробы возвращаются к fixture. Исходная литология остаётся только для чтения; первичный редактор остаётся в будущей интеграции.
- Проба создаётся внутри одного видимого кернового сегмента. Split mapping может создать несколько отображаемых частей одного исходного образца. Пересечение нескольких сегментов одной новой формой, объединение разных номеров проб, полная лабораторная схема каждого материала не реализованы. Один общий вымышленный процент демонстрирует сохранение анализа; новая проба получает 0,000.
- Удаление первого технологического интервала оставляет gap, если нет верхнего соседа. Настройки ширины/порядка/видимости/шкал временные до reload; окно глубины и selection в URL.
- Это расширенный фронтовый прототип: промышленная верификация формул, backend/ACL/audit/утверждение, печать/экспорт, данные БГД и разрезы/карты/3D остаются будущими задачами. Полная промышленная приёмка всех подпунктов РП не заявляется.

## Проверка и доказательства

Typecheck, lint, build и полный test проходят: **36 файлов / 120 тестов**. JS chunk ~881 kB, прежнее предупреждение размера сохраняется.

Предметные тесты проверяют известные численные границы двух методов, направление, округление, отдельные минимумы, продолжение, NaN и среднее; минерализации/цвет и групповое удаление; split/merge и точки промера на контактах; мощности/нули/восстановление, бескерновые вставки, перенос/переворот рейсов; все четыре материала, обратные глубины, части и сохранение анализа. UI/repository тесты проверяют реальные формы, save/reload, миграцию, stale mapping и очистку undo при восстановлении.

Browser smoke: минерализации save; групповое удаление и undo; градиент вверх с шагом 0,2 — 14 строк preview; split КП-пробы; растяжение части без промера и каскадный перенос, undo; split save/reload; создание и сохранение ГС; блокировка DEMO-104. При 390×844 форма доступна, переполнения страницы нет (`document.scrollWidth=375`, viewport 390; горизонтальная прокрутка колонок отдельная). Click/wheel в керне сохранили scrollY=486, сброса вверх нет. Console error/warn — 0.
