## Дельта карты по руководству

| Возможность | Итог итерации |
|---|---|
| Поиск, pan/zoom, выбор/ПКМ/информация, история/guards | Переиспользованы; поиск дополнен типом объекта |
| Сетка: шаг, цвет, толщина, смещения | Добавлены; сохранение редактора/личный просмотр viewer разделены; подписи прореживаются независимо от линий |
| Блок/профиль/сегмент/состав | Добавлены устойчивые опоры/локальные назначения; реальной связи с документами других модулей нет |
| Перемещение исходной скважины из старого РП | Выключено по более новому решению встречи VA-05 |
| SVG, PNG, печатный масштаб, A4–A0, растр/импорт | Переиспользованы; знаки/легенда/сетка согласованы с новым экраном |
| SQL, EMF/WMF, DXF/SHP, EPSG, промышленная типология | Отдельный будущий объём; пустые рабочие команды не добавлены |
