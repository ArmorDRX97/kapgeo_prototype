## Что делать первым

1. Убрать из основного примера карты неподтверждённые цветные области и лишние линии; оставить управление видимостью предметных групп.
2. Перестроить небольшой синтетический пример блоков по скважинам, добавить устойчивые связи точек контура со скважинами и запретить случайное перемещение скважин.
3. Исправить условный знак: круг с внутренним крестом, цвет по типу, линия направления без отдельного креста на конце. Точная таблица цветов и значение пустого/заполненного круга требуют уточнения.
4. Проверить точки технологического горизонта, руды и забаланса по исходным интервалам и общей проекции; различать источник, выклинивание и вспомогательную вершину.
5. Уточнить стадии/типы разрезов и сделать последовательность «разрез → сегмент → скважины» явной, переиспользуя существующие инструменты.
