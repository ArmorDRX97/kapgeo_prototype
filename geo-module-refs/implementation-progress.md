# Реализация геологии — журнал этапов

Обновлено 13.10.2026. Согласованный ограниченный прототип и пять заключительных задач завершены. [Итоговый отчёт](geology-implementation-report.md) описывает весь результат, связь с РП/видео и техническую реализацию; [матрица](requirements-matrix.md) отделяет проверенный объём от расширений.

## Решения пользователя

- 12.10: автономный прототип в ограниченных локальных рамках, без реальных источников, общей БГД/интерпретационной модели, legacy-миграции и backend. Примеры разрезов полностью вымышлены и изолированы.
- 12.10: редактируют геолог и администратор; остальные пользователи геологии просматривают; зафиксированный разрез read-only.
- Для заключительных пяти задач пользователь разрешил самостоятельное принятие решений без дополнительных вопросов.
- Общие вспомогательные опоры существуют только внутри разрезов. Изменение показывает затронутые документы и требует явного применения коррекции.
- Чертёж: SVG, PNG 150 dpi и браузерная «Печать / PDF»; отдельный генератор PDF не добавляется.
- Разломы согласованы как ручные линии без автоматического смещения пластов и связанных границ.
- Литология согласована: ручные замкнутые области с породой, внутренние исключения, скважинные колонки как опора. Редактор подключён. Автоматическая межскважинная корреляция пород не входит в эту модель.

## История проверок до заключительных пяти задач

Следующие 217 тестов и сценарии относятся к предыдущему срезу 12.10.2026. Проверки кровли/пачек ниже исторические: эти функции затем исключены пользователем и удалены. Актуальная приёмка — в итоговом отчёте.

Последний полный прогон после литологии, карты, настроек интерпретации, drag точек и исправления обратной связи Undo/Redo: **55 файлов / 217 тестов passed** (12.10, 23:10, 24,04 с); `npm run typecheck`, `npm run lint`, `npm run build` — exit 0. Остаётся известное предупреждение JS chunk >500 kB. Vitest запускается с TEMP/TMP в `.tmp/design-qa/temp`: системная временная папка ранее давала EPERM до загрузки тестов.

Численные проверки: проекция/МНК/ломаная; 1:N с разветвлением и отверстием; ограничение руды ТИ; пороги 3/0,5 м; граничные интервалы; сглаживание с фиксированными опорами; геометрия областей/исключений; физическая компоновка и таблица всех ОРИ без опор. Repository-проверки: ACL, конфликт, повреждение/quota, общие ревизии двух документов, защита используемых объектов. Восстановленная интерпретация проходит прежние тесты и dirty guard.

Browser QA: официальный Playwright CLI, отдельная локальная сессия, production preview `/kapgeo_prototype/`, частично dev. Проверено:

1. Геолог → корреляция → save-and-continue → интерпретация → возврат → reload со связью/выбором.
2. Создание → профиль/коридор/состав → save/reload → rename → delete. Фильтры/группировка сохраняются в URL.
3. Некорректное сокращение профиля перечисляет зависимости и не применяется. Граничный интервал сохраняет верх/низ.
4. Общая опора двух разрезов → список обоих → публикация без изменения снимков → явная коррекция/Undo/Redo/Save; удаление используемой запрещено.
5. Кровля по дуге → фундамент по кровле → запрет удаления кровли → коррекция исходного ТИ → связанная кровля меняет геометрию.
6. Незавершённая геометрия защищает уход; применение/отмена работают. Locked и R2 не могут редактировать разрезы.
7. КС/ГК/порядок колонок и экранные настройки переживают reload. PNG скачивается; PDF соответствует печатному CSS. Выбор «2, 4» даёт ровно два листа с исходными номерами 2/4 и 4/4; некорректный номер блокирует печать.
8. Отмена/повтор 20 последовательных команд, очистка redo новой командой, Back/Forward между разделами; отмена правок общей опоры не снимает защиту незавершённого исходного интервала.
9. Забаланс: пустое участие → две скважины → связь → save/reload. Руда без поправок сохраняет свою связь, не изменяя corrected. Enter выбирает графическую опору; snap к литоконтакту ГС-101 даёт точную X 36,2874 м и видимую подпись; snap можно отключить.
10. Desktop 1440×900 и mobile 390×844: общая ширина документа 390 px, checkbox 16×16 px, таблицы/графика прокручиваются внутри области. Это проверка затронутого потока, не всей мобильной оболочки.
11. Пустой поиск и неизвестный ID показывают понятный fallback. Escape закрывает диалог создания и возвращает фокус. Повреждённое хранилище не перезаписывается; после восстановления данных реестр открывается. Имитация quota сохраняет ввод и блокирует Save-and-continue. Профиль R5 без geology.view не получает редактор по прямому URL; после проверки возвращён геолог. Console errors/warnings после основных сценариев — 0.

12. Литология: новая область с четырьмя точками и внутренним исключением → Apply/Save → reload; невалидное исключение отклонено, Cancel сохраняет исходные точки. Порода → Undo/Redo; смена режима не раскрывает чужой объект. Изменение родителя с выходом исключения и подтверждаемое каскадное удаление покрыты компонентными тестами. Привязка окисления к верхней ручной границе сохраняет Z=-1. Read-only R2, SVG/PDF и desktop/mobile 390 px проверены. Вкладка не показывает свойство штрихов окисления.

13. Карта: новый профиль двумя кликами → preview → Apply → Undo; сокращение с зависимой геометрией блокируется. Незавершённый первый клик защищает переход; Escape отменяет. Tab/Enter добавляет ГС-107, Undo возвращает состав; mobile 390 px без общей прокрутки.
14. Настройки интерпретации: width 208, порядок, скрытый ГК и шкала КС max=150 переживают reload и возврат из разрезов. У WELL-102 остаются собственные defaults; документы интерпретации побайтно не меняются. Reset настроек переживает reload. Quota/corrupt-preferences покрыты unit tests; при отказе записи настройки работают в сеансе с сообщением.
15. Корреляция: drag выклинивания/граничного контакта/вспомогательного узла, одна команда Undo, Escape, Shift+ArrowUp=1 м. Граничный X остаётся 0; исходные контакты не смещаются. Найденная обрезка граничного маркера исправлена; pointer capture работает вне графической рамки. Маркеров нет в clean-чертежах и у R2; на mobile 390 px нет общей прокрутки. Ручной разлом → Apply → Undo проверен без смещения пластов. После новых сценариев console errors/warnings — 0.

Финальный A3 PDF: **1 лист 420,20×297,01 мм**, МГ 1:2000 / МВ 1:500, линейка **50,000 мм**. A4: **4 листа 297,01×209,89 мм**, МГ 1:1000 / МВ 1:500, нахлёст 10 мм, линейка **49,999 мм**. Размеры отражают округление Chromium. Рендеры таблицы/штампа просмотрены; дополнительная HTML-страница отсутствует. Физический принтер не проверялся.

## Завершение пяти задач — 13.10.2026

1. Ритмопачки и связанные границы удалены; безопасное чтение старых документов/фундамент/URL/Save-cleanup проверены.
2. Независимые сегменты соединяются с направлением, preview промежутка и проверкой зависимостей; Apply/Cancel/Undo/reload работают.
3. Произвольные локальные треки имеют состав/порядок/ширину, общие настройки/overrides и единый экспорт.
4. Короткая/длинная дуга замкнутого контура имеет preview сглаживания/спрямления, сохранение опор/геометрическую валидацию/Undo/reload/repair.
5. Итоговые тесты, browser desktop/mobile, чтение старых документов, полный сценарий создания и SVG/PNG/PDF, расширенный локальный отклик и синхронизация документации завершены.

Финально: **60 файлов / 237 тестов**, typecheck/lint/build — exit 0. JS chunk warning сохраняется. A3 PDF: 420,201×297,011 мм, линейка 50,000 мм; A4 выбранные страницы 2/4 и 4/4: ровно два листа 297,011×209,889 мм. Проверены файлы SVG/PNG, рендеры PDF просмотрены.
