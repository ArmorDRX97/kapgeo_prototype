## Главное для продолжения

«Альфа» описывает комплексную интерпретацию методов ГИС по скважине: электрокаротаж → литология/Кф, ГК → рудные интервалы/Ra/U, ТК → фактический фильтр/отстойник, ИК → металлические элементы конструкции, ТМ → границы цементации, КМр → расширение/обсыпка, РМ → профиль притока/приёмистости. Отдельно работают контрольные измерения, редактор кривых и сборка паспорта. Это существенно шире нынешних трёх режимов KAPGEO.

Существующий KAPGEO сохраняем как основу: литология по каротажу/керну/сводная, ручные технологические интервалы и demo-расчёт по КС, сегментная привязка керна, пробы КП/ГС/ЛГХ/ТП, Canvas-планшет, Undo/Save и независимое локальное хранение. Отображаемая кривая ГК ещё не означает реализованную интерпретацию ГК. Контрольная КС ещё не означает контроль качества измерений.

Рекомендуемое направление следующей работы: расширить существующий подмодуль «Интерпретация» до единого рабочего места методов ГИС; переиспользовать планшет и интервальные операции, добавить предметные результаты и зависимости между методами. Порядок и модель ниже — **предложение для следующей задачи**, не утверждённый объём реализации.
