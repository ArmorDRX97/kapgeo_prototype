# Покрытие инструментов и настроек PDF

К [общей матрице](README.md). «Эквивалент» — тот же результат доступен иначе; «частично» — есть лишь часть поведения; «нет» — не найдено в соответствующем рабочем месте. Перенос desktop-кнопки в другую группу допустим, но наличие похожей кнопки в независимом модуле не закрывает требование.

## D-08: карта профиля, PDF с. 2 / рис. 2.8

Основной код: [ProfileMap](../../src/features/geology-sections/ui/ProfileMap.tsx:28), [ProfileEditor](../../src/features/geology-sections/ui/ProfileEditor.tsx:13), [SectionWells](../../src/features/geology-sections/ui/SectionWells.tsx:10).

| № рисунка | Действие | Есть сейчас / остаток |
|---|---|---|
| 1 | Переместить чертёж | Есть: drag фона ЛКМ, стрелки; не перенос исходных скважин |
| 2–3 | Приблизить / отдалить | Есть: колесо и кнопки в «Отображение» |
| 4 | Степень увеличения | Масштаб есть; отдельного процентного поля/селектора в карте профиля нет |
| 5 | Добавить сегмент | Есть: независимый двухточечный сегмент, клик/точные координаты, preview перед присоединением |
| 6 | Удалить сегмент | Есть: удалить выбранный сегмент, проверка зависимостей и предупреждение. VA-17 |
| 7 | Добавить сопряжённый сегмент | Есть: «Продолжить профиль», новая вершина от прежнего конца |
| 8 | Переместить сегмент | Частично: drag вершины и табличные XY. Нет переноса двух концов выбранного ребра одним движением с сохранением его длины/направления |
| 9 | Соединить сегменты | Есть для независимого сегмента и начала/конца общей трассы; произвольный граф разорванных сегментов не хранится |
| 10 | Выровнять по забою | Есть для выбранного конца и выбранной скважины. Не следует называть это произвольным автоматическим поворотом всего сегмента |
| 11 | Добавить / удалить скважину | Есть: режим состава, клик / Tab+Enter, исключение с предупреждением; исходная скважина не удаляется. VA-17 |
| 12 | Добавить скважины в коридоре | Есть во вкладке «Разрез» → состав скважин; прямого входа из карты нет. Подбор по забоям, preview, добавление без дублей |
| 13 | Диалог прямолинейных сегментов | Есть таблица вершин в «Разрез»; отдельного входа в её редактор из карты и предметной таблицы сегментов нет |
| 14 | Найти скважину | Есть выпадающий выбор скважины на карте с центрированием; это не общий поиск произвольного объекта |
| 15 | Найти разрез | Нет поиска другого разреза внутри карты профиля. Реестр слева позволяет выбрать другой документ, но не подсвечивает его трассу на текущей карте |
| 16 | Найти блок | Нет локальных блоков в модели разреза и поиска/выделения блока здесь. Самостоятельная карта имеет свои объекты, но связи источников нет |
| 17 | Масштаб чертежа | В карте только экранный zoom; физические H/V масштабы доступны в «Чертёж». Не смешивать эти параметры |
| 18 | Закрыть окно | Web-адаптация: перейти на другую вкладку документа. Отдельная desktop-кнопка «OK» не нужна |

Форма геометрии — непрерывная направленная полилиния. Внутренняя вершина общая для двух ребер: перенос одного сегмента потребует явного правила для соседей и проверки ручных областей. Нельзя просто сдвинуть один endpoint и назвать это переносом всего сегмента.

## D-10/11: технология и руда, PDF с. 3 / рис. 2.13 и 2.17

Общие реализации: [CorrelationEditor](../../src/features/geology-sections/ui/CorrelationEditor.tsx:20), [ArcEditor](../../src/features/geology-sections/ui/ArcEditor.tsx:5), [ClosedContourArcEditor](../../src/features/geology-sections/ui/ClosedContourArcEditor.tsx:8), [SharedAuxiliaryEditor](../../src/features/geology-sections/ui/SharedAuxiliaryEditor.tsx:16), [SourceEditor](../../src/features/geology-sections/ui/SourceEditor.tsx:8). Выбор исходных контактов и ограничений — [correlationHandles](../../src/features/geology-sections/model/correlationHandles.ts:10).

| Действие рисунков | Наличие и предел |
|---|---|
| Правая панель инструментов | Есть, три группы: отображение / объекты / координаты. Это уже готовая компоновка, не новая задача |
| Pan / zoom / увеличение | Есть, колесо/ЛКМ/кнопки и вертикальное увеличение; текст/маркеры рабочего разреза имеют постоянный экранный размер |
| Соединить / разъединить интервалы | Есть формы выбора источника/соседа, независимые связи по слоям; не графический режим последовательного выбора двух интервалов на полотне |
| Добавить / удалить дополнительный интервал | Есть локальные/общие вспомогательные опоры с MD и защитой связанных интервалов. Нет режима создания двумя кликами по вертикальному продолжению ствола и удаления кликом по опоре |
| Добавить / удалить вспомогательную точку | Есть таблица точек дуги и удаление узла. Добавление помещает новый узел между последним узлом и концом; нет вставки в ближайший отрезок контура в указанном месте |
| Переместить точку | Есть drag выбранного разрешённого маркера, клавиатура и численный ввод. Fixed-опоры не превращены в свободные |
| Сместить точку | Отдельного legacy-режима нет. В РП с. 155 это **один клик в новом месте → перемещается ближайшая допустимая точка**; это не просто ввод dX/dZ. Стрелки/drag дают эквивалент изменения координат, но другой сценарий выбора |
| Скруглить / спрямить | Есть обработка дуги между выбранными вершинами, короткий/длинный путь, preview. Нет полной панели выбора старых методов/параметров сглаживания и выборки двух вершин двумя кликами. Нынешние прототипные сплайны нельзя объявить идентичными старым методикам |
| Undo / Redo | Есть общая история документа до 40 команд в верхней строке. Она шире истории отдельного desktop-слоя; переносить дублирующие кнопки вправо не требуется |
| Сброс | Есть подтверждаемый сброс связей/ручных точек слоя. Источники сохраняются |
| Исправить | Есть `repairSection`, preview коррекции локального источника и явная коррекция общих опор. Отдельной универсальной команды с тем же названием/всеми правилами desktop-системы нет |
| Настройка / вид | Есть общие и индивидуальные колонки, шкалы/видимость кривых, дорожки, offsets. Не все старые поля имеют исходные данные |
| Режим ритмопачек (рис. 2.13 №16) | **Исключён пользователем. Не реализовывать и не считать незакрытой задачей** |

Необходимая доработка — унифицировать графические команды и доступ к уже имеющимся моделям. Полный повторный редактор технологии/руды не нужен. Любые новые pointer-режимы должны использовать существующие ограничения X/Z, валидацию и историю.

## D-12: окисление, PDF с. 4 / рис. 2.18

Код: [GraphicEditor](../../src/features/geology-sections/ui/GraphicEditor.tsx:15), [snap](../../src/entities/geology-section/lib/geometry.ts:49), [перемещение точки](../../src/features/geology-sections/model/manualPoint.ts:4). Определения жестов дополнительно проверены по РП с. 169–170.

| № рисунка | Действие | Результат сверки |
|---|---|---|
| 3–6 | Pan / увеличение | Есть |
| 7 | Добавить линию | Есть несколько ручных линий. Старт создаёт две исходные точки; затем можно добавлять/перетаскивать. Рисование новой линии с пустого контура полностью кликами адаптировано лишь частично |
| 8 | Удалить линию | Есть удаление выбранного объекта и общий Undo |
| 9 | Переместить линию | Есть численный перенос всех точек dX/dZ. Нет выбора линии и перемещения целиком мышью / двухкликового определения вектора |
| 10 | Замкнуть / разомкнуть | Есть флажок выбранной линии |
| 11 | Направление контура | Есть обратная сторона штрихов и разворот порядка точек. Сторона и порядок — разные параметры, не следует случайно менять оба |
| 12 | Добавить точку | Есть кнопка и клик, **но новая точка дописывается в конец** (`points: [...current.points, ...]`). По РП нужна вставка в ближайший сегмент существующей линии |
| 13 | Удалить точку | Есть действие строки координат. Отдельного режима удаления точкой на графике нет |
| 14 | Переместить точку | Есть drag и таблица/стрелки |
| 15 | Сместить ближайшую точку | Нет отдельного однокликового режима; описание РП соответствует ближайшей точке, не численному переносу всей линии |
| Контекст рисунка: цвет керна | В текущих `SectionWellSource` есть литология/кривые/интервалы, но нет отдельной цветовой колонки керна. Нельзя обозначить литоколонку как керн без нового локального источника |

Snap к литоконтактам при добавлении/drag реализован. Он не означает автоматическую литологическую корреляцию или перенос исходных контактов руды.

## D-13: настройки чертежа, PDF с. 4 / рис. 2.20

Код независимо прочитан после узкого read-only поиска Luna-worker: [DrawingEditor](../../src/features/geology-sections/ui/DrawingEditor.tsx:17), [SectionDrawing](../../src/entities/geology-section/model/types.ts:29), [drawingLayout](../../src/entities/geology-section/lib/drawing.ts:18), [TrackSettingsEditor](../../src/features/geology-sections/ui/TrackSettingsEditor.tsx:6). Ниже проверяется именно чертёж разреза, а не экспорт отдельной карты A0–A4.

| Поле / область старого окна | Текущее покрытие |
|---|---|
| Масштаб по плану / по высоте | Есть независимые H/V знаменатели |
| Верх / низ видимой области | Есть, только внутри рабочего Z-диапазона |
| Обрезать слева / справа | Есть эквивалент через конечные координаты «Слева/Справа», а не величину отрезаемого поля. Следует объяснить различие подписей; правый bound не равен «обрезать справа» |
| Поле плана | Есть «Высота плана, мм»; старое окно использует см. Это одна сущность с другими единицами |
| Смещение профиля в плане | Нет; положение задано формулой мини-плана |
| Разделитель | Нет отдельной настраиваемой области между планом и разрезом |
| Нижнее поле | Общий margin бумаги есть, самостоятельного поля между разрезом/таблицами/нижней рамкой нет |
| № приложения | Нет |
| № листа | Автоматическое `Лист n/N` есть; заданного номера/начала нумерации для приложения нет |
| Описание чертежа | Есть примечание и название варианта; вывод примечания в штамп ограничен 120 символами |
| Скважины: глобальная видимость / индивидуальный список | Нет отдельных настроек варианта; используется весь `section.wellIds` |
| Технологический горизонт | Есть, флажок называется «Технологическая толща» |
| Оруденение без поправок / оруденение / техзабаланс | Есть независимые слои. Таблица ОРИ выбирает первый включённый источник по фиксированному приоритету `ore → uncorrected → offbalance`, а не показывает сразу три набора |
| Зоны окисления | Есть |
| Литология | Есть для ручных областей. Проверено: отключение 22 → 0 областей, **81 элемент колонок остаётся**. Нужны отдельные понятные настройки областей и колонок либо единое правило |
| Разломы | Есть ручные линии; не смещают пласты |
| Блоки | Источника нет; в штампе «Блоки / пересечения: нет данных». Нет поля видимости и настройки таблиц блока |
| Параметры рудных интервалов | Есть таблица MD интервалов, но не полный выбор подписей/метрик и переключатель их вывода на сам график |
| РП детальной / эксплуатационной разведки / технологические | **Ритмопачки исключены**, не добавлять флажки из старого окна |
| Статический уровень | Нет источника/поля в текущем разрезе; отдельное расширение после определения данных |
| Граница мерзлоты | Нет источника/поля; не путать с уже удалённым параметром кондиционных лимитов БГД |
| Условные обозначения, см | Нет размера/состава печатной легенды. Контрольная линейка 50 мм — другой объект, она не заменяет легенду |
| Скважины: фильтр / цвет керна / литология / ствол | Есть общие настройки колонок самого разреза; нет независимых полей варианта чертежа для фильтра/цвета керна/ствола и выбора скважин |
| Скважины: колонки | Чертёж наследует `columnSettings` разреза; индивидуальные варианты печатных настроек колонок не хранятся в `SectionDrawing` |
| Блоки / РП / доп. оруденение | Полных отдельных редакторов этих печатных таблиц нет; РП исключены, остальные требуют локальной модели |
| Несколько вариантов / масштабы / слои | Есть создание/копирование/выбор/сохранение вариантов |
| Формат и страницы | A4/A3, ориентация, нахлёст, порядок/центрирование, диапазон листов; A0–A2 относятся к экспорту другой карты, не к этому редактору |
| Вывод | Векторный SVG, PNG 150 dpi, браузерная печать/PDF. Физическая печать в этом аудите не выполнялась |

**Согласованность геометрии:** графический разрез учитывает `segmentWells`, а таблица DrawingPage считает станцию через ближайший `projectToProfile`. В контрольном примере расхождение составляет примерно 146,92 м. Исправление общей проекции приоритетнее косметического добавления полей штампа.

**Согласованность знаков:** план чертежа отдельно рисует пустые круги и полилинию без общего знака устье→забой. Наличие общего знака в экспорте самостоятельной карты не закрывает это место.
