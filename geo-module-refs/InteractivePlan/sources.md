# Источники и покрытие

Дата: 14.10.2026. Архив открыт по прямому запросу пользователя в этом исследовании. Изучались конкретные документы ниже; исторические analysis-artifacts не использовались как первичное доказательство. Номер страницы — физическая страница PDF, начиная с 1; для основных приведённых разделов G19/GM25 он совпадает с напечатанным номером. Для DOCX указан раздел и номер непустого абзаца в локальной текстовой выгрузке, не страница Word.

## Приоритет источников

1. Текущие решения пользователя и `docs/ui-ux/`, включая автономность прототипов и новую структуру меню.
2. **GM25** — прямое описание редактора картирования; **G19** — прежние карты и предметные операции.
3. **TZ** и **FT** — описание целевой большой системы. Межмодульные записи и промышленная ГИС из них не становятся автоматически согласованным объёмом автономного прототипа.
4. **TP19/TM19** — граница смежного технологического функционала; **OV** — обзор системы, не руководство редактора.
5. Скриншот пользователя — визуальное доказательство конкретного состояния, без возможности восстановить скрытые меню и значения легенды.

## Различия, которые нельзя потерять

- G19 §1.29 — общая карта БГД, а §2.5.3 — карта именно состава и профиля разреза. GM25 — отдельные картографические проекты и редактируемые слои. Нужен новый документ проекта плана.
- G19 §3.5 и §3.9 содержат подсчётные блоки, рудные показатели, распределения, изолинии и ячейки Вороного. Эти вычисления принадлежат подсчёту запасов/моделированию и не следуют из наличия редактора GeoMap.
- В TP19/TM19 карта обслуживает добычной комплекс и дату состояния. Проект картирования с датой составления — другой объект; не следует молча превращать дату проекта в исторический срез данных.
- Слово «планшет» в A18 обозначает скважинный планшет по глубине. Он не заменяет план XY.
- Цвета контуров в GM25 настраиваются пользователем. Легенду пользовательского кадра нельзя вывести из цвета линии.

## Ограничения доказательств

Не установлены точная сборка программы на кадре, EPSG/СК и единицы внешних файлов, точные параметры кардинального сплайна, полная формула импорта, семантика красных/бирюзовых линий кадра, регламент расчёта продуктивности, перечень стилей и условных знаков. Отсутствие описания в выбранных руководствах не доказывает отсутствия функции в исполняемой программе. Эти пункты сохранены в [открытых вопросах](./implementation-approach.md#открытые-вопросы).
